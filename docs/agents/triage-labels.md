# Triage labels

Label vocabulary used by the `triage` skill. Each role maps to a GitHub Issues label.

| Role             | Label              |
|------------------|--------------------|
| Needs triage     | `needs-triage`     |
| Needs info       | `needs-info`       |
| Ready for agent  | `ready-for-agent`  |
| Ready for human  | `ready-for-human`  |
| Won't fix        | `wontfix`          |

These are the default canonical labels. Override any row above if your tracker already uses different strings for the same concept.
