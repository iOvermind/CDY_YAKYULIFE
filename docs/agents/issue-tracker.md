# Issue tracker

Issues for this repo are tracked in **GitHub Issues**.

- **Repo:** `iOvermind/CDY_YAKYULIFE`
- **CLI:** [`gh`](https://cli.github.com/)
- **Create:** `gh issue create --repo iOvermind/CDY_YAKYULIFE --title "…" --body "…"`
- **List:** `gh issue list --repo iOvermind/CDY_YAKYULIFE`
- **View:** `gh issue view <number> --repo iOvermind/CDY_YAKYULIFE`
- **Close:** `gh issue close <number> --repo iOvermind/CDY_YAKYULIFE`

## PRs as a request surface

Disabled. External pull requests are **not** treated as triage input.
