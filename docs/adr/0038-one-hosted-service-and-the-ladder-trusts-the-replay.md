# ADR 0038：一個自架服務，天梯信任的是重跑而不是連線

## 狀態

已採用。取代 [ADR 0001](0001-tauri-react-architecture.md) 第 1 點的「Tauri 打包
桌面端」與第 3 點的整段「兩棲資料庫與防作弊機制」。該 ADR 的第 2 點（資料解耦、
規則資料化）完全保留——那一條至今是這個專案最正確的決定。

## 背景

ADR 0001 假設的是**兩棲發行**：網頁版加上 Tauri 打包的桌面版，桌面版離線可玩、
寫本機 SQLite，結算時用 Token 同步 AP。天梯則被排除在外——「任何『離線／本地』
產生的生涯紀錄一律被隔離」，要上榜「必須連線進行遊戲（伺服器即時驗證），實行
最嚴格的隔離機制」。

三年下來實際長成的東西不是那樣。

**離線那一半從來沒有落地。** `client/src` 裡 `localStorage` 與 `IndexedDB` 一個都
沒有，Tauri 只是一個外殼。沒登入的玩家今天沒有任何持久化——不是「離線存在本機」，
是「什麼都不存」。

**線上那一半長成了另一個形狀。** [ADR 0007](0007-online-accounts-and-server-verification.md)
落地的是「開局向伺服器登記並凍結天賦 → 離線玩完 → 上傳重播日誌 → 伺服器用凍結的
那組天賦重跑、自己算成就」。那不是 Token 同步，也不是即時驗證，但它比兩者都強：
**伺服器不相信客戶端報上來的任何數字，它自己算一遍。**

**而「必須連線進行遊戲」防的東西，其實不需要那麼貴的手段。** 那條規定真正擔心的
是離線重刷——玩家在本機跑一萬顆種子，挑一顆潛力最漂亮的再登記。這件事今天確實
做得到（`startCareer` 只凍結天賦，種子由客戶端決定）。

## 決定

### 1. 一個自架服務，離線不再是目標

`docker compose` 起 app 與 Postgres，經 tunnel 對外，玩家連網址就玩。`client/`
不再是「桌面端的前端」，它就是那個服務送出去的遊戲包。

**Tauri 轉 legacy、不再維護。** 連帶作廢的是 ADR 0001 的本機 SQLite、Token 同步，
以及 ROADMAP 階段一的「實作 SQLite / IndexedDB 介面卡」。存檔只有一種形狀：
伺服器上的 Postgres。

沒有登入的人照樣玩得完整段生涯——他只是不留紀錄。這與過去一樣，差別只在我們
不再假裝將來會替他把紀錄存在本機。

### 2. 自選種子是合法玩法

種子不是規則。挑一顆好種子改變的是這個球員生下來是什麼樣子，不改變任何一條計算
——那更接近「選一個開局劇本」，而且那段生涯仍然得由玩家親手打完。因此**不擋、
不標記、不隔離**，自選種子的生涯與伺服器隨機的生涯在榜上平起平坐。

ADR 0001 的「最嚴格的隔離機制」隨之撤銷。

### 3. 天梯信任的是重跑

上榜的唯一條件是**伺服器重跑得出同一段生涯**：用開局登記時凍結的天賦重播日誌，
自己算成績與成就，客戶端報上來的只拿來比對。重現得出來就算數（`careers.verified`），
重現不出來就不進榜。

這一條同時吃掉了「自訂規則局」這個類別。在自架模型下規則資料由伺服器送出，玩家
改了自己那份，伺服器重跑必然對不上——**它不是一個要另外標記的身分，它就是驗證
失敗**。`CONTEXT.md` 那條「自訂規則局不上天梯、不結算 AP」因此不再需要一套獨立的
標記機制；階段一.七的參數編輯器若要保留，得由伺服器承認那組參數，否則那一局本來
就進不了榜。

### 4. 「天梯」升格為通稱

原本它專指全球競技排行榜。現在它是**排名榜的通稱**，用範圍區分：

- **個人天梯**：你自己打過的每一段生涯互相排名。
- **全伺服器天梯**：這台服務上所有玩家的生涯一起排名。

兩者共用同一張表、同一套驗證、同一份欄位清單與同一組資格規則——差別只在查詢時
限不限 `user_id`。

### 5. 榜單上的數字是歷史，不是同一把尺

每一列帶著它結算當下的 `ENGINE_VERSION`。規則改版之後舊生涯**留在榜上**，只是
標得出來是舊規則的產物。[ADR 0002](0002-deterministic-rng-and-replay-log.md) 已經
說了跨版本不保證重現，所以沒有「用新引擎重算舊生涯」這條退路——那不是更正，那
會走出另一個人。

榜單是歷史，不是競技場。因為改了一條規則就抹掉玩家的一段人生，代價比尺不齊高。

## 後果

- **少了一整條相容路徑。** 沒有本機存檔就沒有「本地與伺服器對不上時怎麼和解」
  這個問題——那套和解規則比榜單本身難寫。
- **玩家換裝置就換不到紀錄**，除非登入。這是自架服務的正常代價。
- **服務掛了就沒得玩。** 兩棲架構原本要買的就是這個保險，現在明確不買了。
- **開發環境需要 Docker。** 換掉了原本的 Rust 工具鏈需求，總量沒有變多。
- ADR 0001 的第 2 點（資料解耦）不受影響，而它正是讓這次轉向便宜的原因：規則
  全在 JSON 裡，伺服器與客戶端讀的是同一份。
