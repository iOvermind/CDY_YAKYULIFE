# ADR 0020：年資可以拒絕下放，但拒絕要付代價

## 狀態

已採用。

## 背景

一軍合約有效期間，球員會被系統無條件送回二軍（ROADMAP #18）。玩家的抗議很直
接：「我還在一軍合約內，憑什麼說下放就下放。」

查了各聯盟的實際規則，答案分歧：

- **MLB**：服務滿五年的球員不能被無條件下放到小聯盟——這是勞資協議寫死的權
  利，選手可以拒絕。但球團的對應手段也很硬：拒絕之後可以直接把人放進讓渡名
  單（DFA）。年資是護身符，不是免死金牌。
- **NPB／KBO／CPBL**：沒有對應制度。支配下登録的升降由球團決定，年資換來的是
  FA 資格，不是拒絕下放的權利。

所以這不是一條可以一體適用的通則，而是**一個體系的規則差異**。

## 決定

1. `TransferOrg.refuse_demotion_after_years` 是資料驅動的門檻，與
   `domestic_after_years`（ADR 0019）同一個 pattern：缺席表示這個體系沒有這條
   規則。目前只有 `MiLB`（美職體系）填 5。
2. 年資看的是**該體系累計的一軍年份**（`#orgYears`），與外籍身分同一個計數口
   徑——拿的是在那個聯盟站穩了多久。
3. 有資格的人在年末的下放遞約裡多一個選項：「行使年資權利，拒絕下放」。**即使
   沒有任何其他聯盟的邀請也要問**——那正是這條規則最有意義的時候。
4. 拒絕之後擲一次骰：**釋出機率就是那一次下放判定用的機率**
   （`MovementResult.pressure`）。成功留下就回到原本的層級；失敗就進讓渡名
   單，走與一般戰力外相同的尋路（`#fallback`），球團付全額買斷。

## 為什麼釋出機率不另外開參數

跟不上得越多，球團越想把你送下去，也就越不願意為了留你在一軍而浪費一個名額。
這兩件事本來就是同一個量。再長一個 `refuse_release_chance` 只會多出一個要校準
的旋鈕，而它的正確值永遠會被推回「跟下放壓力成正比」——那就直接用那個數字。

## 後果

- 玩家在一軍合約內拿回了一點主導權，但那是一個**真的有風險的選擇**：成績差到
  一個程度時，拒絕下放幾乎等於自請離隊。
- 只有美職體系有這個選項。日職與中職的玩家看不到它，這是刻意的差異，不是遺漏。
- `pro.ts` 的 `MovementResult` 多帶一個 `pressure`，讓 `game.ts` 不必重算一次
  判定——重算會用掉另一個亂數，破壞重播。
