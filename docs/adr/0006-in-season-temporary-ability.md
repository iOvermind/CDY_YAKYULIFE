# ADR 0006: 當季暫時能力——非成長性的獎勵不進能力表，只影響那一季的成績

## Status

Accepted

## Context

能力點的授予目前只有一條路：進**蓄力槽**（`#carry`），滿一級就把能力值 +1，沒滿就
存著。那條路假設「拿到點數 = 這個人變強了」。

這在事件卡與訓練骰上是對的——它們本來就是成長。但接下來要做的系統不是這個性質：

- **感情事件**給的是「戀愛使人容光煥發」「心定了，身體就穩了」。那不是成長，那是
  狀態。一個 34 歲、體力早就點滿的老將結婚，說他因此變強是不合理的，但說那一年
  他狀態特別好是合理的。
- legacy 已經有這個東西：`addAbStat()` 把溢出的點數轉成 `S.pendStat`，直接加在
  當季成績的計算上，並誠實地寫在卡片文字裡（「溢出 2 點轉為本季成績加成」）。
- 之後的**成就點數與天賦商店**、**職業期的國際賽徵召**都會遇到同樣的問題：獎勵要
  發給一個可能已經點滿的人。

照現況做的話，這些系統會變成成長路線：**玩家會為了練體力去談戀愛**，而那不是我們
想要的遊戲。

## Decision

**非成長性的獎勵改發「當季暫時能力」：只餵給球季模擬，不寫回能力表。**

```
感情事件給「體力 +2」
  → 不進蓄力槽
  → 記進當季暫時能力
  → 球季模擬時，能力值 = 真實能力 + 當季暫時能力
  → 球季結束後歸零
```

**為什麼不是「溢出才轉」。** legacy 的 `addAbStat()` 是先加點、溢出的部分才轉成
成績加成，因為它的能力有硬天花板。我們的成長模型沒有——天賦到頂只是讓下一級變貴
（`above_ceiling_multiplier`），點數永遠花得出去。照抄那條規則的話它幾乎不會觸發，
而點滿的老將結婚仍然會「變強」，那正是要避免的事。

因此界線畫在**獎勵的性質**上，不是在數值的溢出上：

- **成長性的獎勵**（訓練骰、大賽點數、事件卡）進蓄力槽，永久改變這個人。
- **非成長性的獎勵**（感情、日後的成就與國際賽）發當季暫時能力，只改變這一年。

一個 34 歲的老將結婚，說他因此變強是不合理的，但說那一年他狀態特別好是合理的。

四條界線：

**1. 它只影響那一季的成績。** 出賽數、各項率、投手定位都吃它——因為那些問的是
「他今年打得怎麼樣」。

**2. 它不影響身價。** 薪資、落地層級、挖角門檻、合約年限、輪值線都用**真實能力**。
那些問的是「這個人值多少」，而一次婚禮不會改變答案。

**3. 它不顯示在能力表上。** 能力表是這個球員的資產負債表，寫進一個明年就消失的
數字會讓玩家誤以為自己練起來了。卡片文字要誠實說明它是當季的。

**4. 它不寫進生涯紀錄。** 逐段紀錄存的是成績，成績已經包含它的效果了；再存一份
暫時能力只會讓結算時重複計算。

## Considered Options

**溢出就丟掉（現況）**——最簡單，而且「練到頂就是練到頂」是誠實的。否決原因：那讓
所有非成長性的獎勵對高天賦球員失效，而感情、成就、國際賽全都是非成長性的獎勵。
玩家看到卡片寫著 +2 而數字沒動，會當成 bug。

**溢出改成永久突破天賦上限**——不必新增概念。否決原因：天賦上限是這個遊戲最核心的
稀缺性，開一道「談戀愛可以突破」的門會讓整套成長經濟失去意義。

**照 legacy 做成「成績加成」——直接加在成績數字上**——最忠於原版。否決原因：那是一
條繞過能力模型的旁路。成績是從能力推導出來的（`gamesPlayed`、各項率），另開一條
直接改成績的管道等於有兩套真相，而且它沒辦法回答「加成 +3 是加在打擊率還是全壘打
上」這種問題。改成加在**能力**上再推導成績，效果一樣，但只有一套真相。

**感情的獎勵照樣進蓄力槽（現況的延伸）**——不必新增概念。否決原因：那會讓談戀愛
變成一條成長路線。一個人的體力不會因為結婚而永久提升，而如果會，那玩家就該為了
練體力去談戀愛——那不是我們想要的遊戲。

**不設上限，暫時能力可以無限疊加**——不必寫夾擠邏輯。否決原因：連續幾年的好事會
讓一個人的當季能力遠超他的天賦，成績單會出現無法解釋的一年。

## Consequences

**正面**

- 感情、成就、國際賽這些**非成長性的獎勵**對任何天賦的球員都有意義。
- 高天賦球員與點滿的老將拿到的回報形狀不同，但都有回報——那正好對映真實：年輕人
  變強，老將靠狀態。
- 只有一套真相：所有成績仍然由能力推導，暫時能力只是把能力抬高了一年。
- 「今年狀態特別好」第一次有東西可以承載。生涯年表裡那個突出的球季有了解釋。

**負面**

- 球季模擬的輸入多了一個來源，除錯時要記得成績可能不是由能力表上的數字算出來的。
  卡片文字必須誠實寫明，否則玩家對不起來。
- **平衡校準的基準會動**：暫時能力讓平均成績略微上移，分級門檻要重跑。
- 「能力」這個詞從此有兩個意思（真實能力與當季能力），程式碼與文件都要講清楚是
  哪一個。`CONTEXT.md` 已收錄「當季暫時能力」一詞。
- 重播的決定性不受影響（它由既有的子序列產生），但**存檔格式**日後要記得它是
  per-season 的暫存值，不該寫進生涯紀錄。
