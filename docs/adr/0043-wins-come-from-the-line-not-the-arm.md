# ADR 0043: 勝投是成績打出來的，不是能力換來的

投手的勝敗改由**這一季的成績**與**球隊的戰績**相撞算出來，不再由能力直接換算。
能力只透過成績間接進來。

## 背景

使用者的回報是「投手勝投異常多，爛隊也會拿 32 勝 0 敗這種戰績」。實測證實了一半：
能力 75 的先發在五成隊平均 23.1 勝、在六成五的隊平均 29.7 勝，量到過 35 勝 0 敗
——整季每一場先發都贏。爛隊那一半不成立（勝率三成的隊最高只到 18 勝 5 敗），但
26 到 32 勝在強隊確實是常態。

成因有兩個，而且是同一個結構的兩面：

**勝與敗是兩條互不相干的式子。** 勝投是 `25 × 先發佔比 × 能力係數 × 球隊係數`，
敗投是 `16 × 先發佔比 × max(0.2, 1.2 − 能力係數) × 球隊係數`。能力係數在能力 75
就抵達 1.0，於是勝投打滿錨點的同時，敗投的乘數掉到地板 0.2——**一條爬到頂、另一
條掉到底，中間沒有任何東西保證兩者加起來合理**。35 勝 0 敗就是這樣長出來的。

**勝敗直接看能力。** 那句話在棒球裡是錯的。一名投手的勝敗是「他讓對手得幾分」與
「他的球隊得幾分」相撞的結果；能力決定的是前者，而且是透過成績決定的。一個投得
很好但那年運氣差、被打爆三場的人，勝投就該少——舊模型看不見那件事，因為它根本
沒有讀他的成績。

## 決定

**兩段式賠率，輸入是 ERA+ 與球隊勝率。**

```
賠率W = (隊勝率 / (1 − 隊勝率)) × 0.54 × (ERA+/100)^1.5
勝投  = 先發場次 × 賠率W/(1+賠率W)

剩餘   = 先發場次 − 勝投
賠率L = ((1 − 隊勝率) / 隊勝率) × 1.174 × (100/ERA+)^0.75
敗投  = 剩餘 × 賠率L/(1+賠率L)
無關勝敗 = 剩餘 − 敗投
```

三個性質是這個形狀選出來的理由：

*   **決定率是導出的，不是設定的。** 沒有任何一個參數說「先發場次有七成留下勝敗」，
    但實測自己落在 0.66 到 0.79，現實約 0.70。兩段相扣的結構把它逼了出來。
*   **兩個常數不是自由參數。** `1.174` 由「聯盟平均投手在五成隊必須勝敗各半」反解；
    `0.75` 由 1978 年基德利那一季（隊 .613、ERA+ 208、35 先發、25 勝 3 敗）反解。
    同一組參數對他的勝投預測是 25.2 勝，實際 25 勝。
*   **敗投的指數遠低於勝投的指數。** 那句話的意思是**王牌的敗投少，主要是因為他贏
    得多，不是因為沒贏的場次都變成無關勝敗**。指數若拉平，一個 ERA+ 200 的人會打出
    近乎不敗的球季，而那不是真的。

**後援走另一條路：機會 × 成功率。** 先發那一套套不上——終結者一年只有幾場留下勝敗，
他的價值在救援，而救援機會是球隊給的。

```
救援機會 = 球隊勝場 × 小差距比例      比例隨球隊變強而下降
成功率   = 0.85 × (ERA+/100)^0.16
```

**機會是球隊給的，成功率是自己的。** 一支爛隊的鐵門終結者機會很少，一支強隊的爛
終結者機會很多但守不住——兩件事分開之後，救援數才有得對帳。小差距比例隨球隊變強而
下降是刻意的：**強隊贏得多，但大勝也多**，救援機會不成比例地增加。成功率的指數只有
0.16，99% 的情形自己就落在 0.70 到 0.95 之間，因此不設硬上下限——那正是真實的窄帶，
再強的終結者也會被打爆幾次，再差的也守得住大部分的三分領先。搞砸的機會有一部分變成
敗投；撿勝則與投得好不好幾乎無關，只與上場次數和球隊會不會逆轉有關。

**國際賽沒有球隊戰力表，勝率另外推。** 拿那一屆的名次去推是循環論證——名次是結果。
改由母國頂級聯盟當年的**浮動 par** 對上賽會自己的 par，走引擎現有的畢氏公式。中職
par 44 對賽會 52 推出 .417：台灣隊是個有機會咬人的弱隊，而且中職的 par 逐年浮動，
代表隊的強弱會跟著世代走。

## 替代方案

**畢氏公式：他自己的失分率對上球隊的得分。** 與勝利份額那邊同源，最漂亮。放棄的
理由很實際：**引擎沒有模擬球隊得分**，只有球隊勝率。硬要湊出一個得分等於再發明一
個模型。

**ERA+ 決定一半、球隊勝率決定一半，兩者相乘。** 比舊版清楚，但兩個乘數仍然各調各
的，強弱隊的差距由一個手調係數說了算——那正是舊版的病。

**只吃 ERA+，球隊只影響決定場數。** 最單純，但爛隊的王牌照樣打出高勝率，而那正是
使用者回報的東西。

## 後果

*   3025 個真實生涯投手球季的實測：最多 22 勝 4 敗，20 勝以上佔 0.2%，救援最多 49 次，
    單季最多 236 局、274 次三振。26 到 32 勝消失了。
*   十勝以上不敗的球季四個（0.13%）。**這是刻意留著的**：2013 年田中將大 24 勝 0 敗
    是真的發生過的事。靶心是平均值落在紀錄之下，靠波動與抖動在極端運氣好時破得了，
    而不是夾死在紀錄以下。
*   爛隊的王牌現在真的會吞敗：能力 75 在勝率三成的隊是 11.7 勝 13.5 敗。
*   勝敗踩在 ERA+ 上，因此**這份決策依賴 [ADR 0042](0042-runs-allowed-share-the-batters-ruler.md)**
    ——自責分必須先由事件推導出來，勝敗才有東西可讀。兩者是同一批改動的兩半。
*   抽取順序改變（自責分必須排在勝敗之前），引擎版本號跳到 6，舊的重播日誌一律拒絕。
