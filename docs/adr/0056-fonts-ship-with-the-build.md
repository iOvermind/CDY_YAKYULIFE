# 0056. 字型隨產物出貨，不從 Google Fonts 載入

日期：2026-09-26

## 狀態

已接受

## 背景

四套主題各自指定字型：電子看板用 DotGothic16 點陣字、報紙版面用 Noto Serif TC 襯線字，其餘用 Noto Sans TC 與 IBM Plex Mono。這些字原本由 `index.html` 的 `<link>` 從 Google Fonts 載入。連不到 Google 的時候（防火牆、擋第三方網域、離線）一律退成系統字，電子看板與報紙版面就只剩配色，認不出是哪一套；而遊戲除了這一行之外，沒有任何東西依賴外部網域。

## 決策

**字型改用 npm 的 `@fontsource` 套件，隨前端產物一起出貨**（`client/src/ui/fonts.ts`），`index.html` 不再連 Google。

中文字型整套有數十 MB。`@fontsource` 用的是和 Google 一樣的切法：每個字重依 unicode-range 切成上百片小檔，瀏覽器只下載畫面上出現過的字所在的那幾片，所以玩家實際下載的量和以前相當。

字重只載介面用得到的那幾種（與原本的 Google 連結同一組）。

## 考慮過的其他做法

- **裁成只含用到的字**：檔案最小，但玩家自己輸入的名字若含其他字會退成系統字，而且每次改文案都得重新裁。
- **只內嵌兩套小字型，中文照舊從 Google 載入**：產物最小，但離線時主題 c 的襯線字與所有中文仍然會退掉——問題只解了一半。

## 後果

- 前端產物從約 1 MB 變成約 47 MB，幾乎全是字型檔。其中一半是給不支援 woff2 的舊瀏覽器用的 woff，現代瀏覽器不會下載它們；變大的主要是 Docker image。
- 上千條 `@font-face` 併進了主 CSS（約 1.1 MB，gzip 後約 460 KB）。以前這份宣告是 Google 那邊另一個請求，一樣會擋住首次繪製；現在它跟著帶雜湊的檔名可以長期快取。
- **canvas 不會自己去要字型分片。** 生涯成績圖畫字之前要先用圖上的文字呼叫 `document.fonts.load`，否則畫面上沒出現過的字會用備援字體去量、去畫（見 `careerImage.ts` 的 `loadFonts`）。
