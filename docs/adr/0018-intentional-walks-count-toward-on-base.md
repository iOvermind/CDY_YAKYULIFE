# 故意四壞計入上壘，且恐懼值只吃 d

## Status

accepted

## Context

`obp_king` 的得獎率是 12.9%，其他打擊類頭銜都在 1–2%。追下去發現 OBP 分子漏了故意四壞：
`(hits + bb) / pa`，而 `bb` 不含 `ibb`。門檻線那側同樣漏算，所以偏差不會互相抵銷——
反而讓「上壘型怪物」在真實名單裡被系統性低估，門檻卻照樣訂在低點。

補上 `ibb` 之後冒出第二個問題：恐懼值 `Dom` 原本是能力加權和除以寫死的 180，
而 180 是在大聯盟 par 59 上校準的。par 44 的中職，連聯盟第一名（能力約 62）都構不到
門檻 1.0——整條敬遠機制在低階聯盟直接消失。

## Decision

兩件事：

1. **`ibb` 計入 OBP 分子**：`obp = (hits + bb + ibb) / pa`。打線與門檻線兩側同時修，
   大聯盟的既有校準因此不動。

2. **能力先平移到基準聯盟（par 59）再算恐懼值**，不是把除數隨 par 縮放：

   ```
   Dom = (Σ aₖwₖ − Σw × (par − 59)) / 180
   ```

   平移量是權重和本身（1+1+1−0.25 = 2.75），不是新的自由參數：全能力齊平在自家 par
   的球員，在任何聯盟都必須拿到同一個 Dom，這就把平移量釘死了。

   結果是全聯盟共用同一條觸發線 `d > +6.5`。

## Considered Options

**除數隨 par 等比縮放**（`divisor = 180 × par/59`）：中職觸發線掉到 `par+4.8`，
聯盟裡一票人都被敬遠，比大聯盟還浮濫。

**除數隨 par 線性縮放，斜率刻意壓在 2**（比等比的 3.05 平緩）：中職觸發線 `par+10.5`，
越低階的聯盟越難構到敬遠。這個結果本身講得通——中職投手陣容薄，繞過這棒去面對下一棒的
收益沒那麼確定。捨棄的理由是它跟模型別處的立場衝突：`proLineAt` 裡每一條率（安打、
全壘打、盜壘）都只吃 `d`，一個 d=+6 的打者在中職和大聯盟打出一樣的成績。任何除數縮放
都做不到這件事——`Dom = (par+d)·2.75 / (180 − (59−par)·s)` 不管 s 取多少都仍是 par
的函數。要讓 IBB 也只吃 d，只能改分子。而且斜率是一個純靠手感訂的新參數。

## Consequences

低階聯盟現在也有敬遠，數量與大聯盟同等 d 的球員相同。**這是刻意的**：如果覺得中職
不該有那麼多敬遠，該動的是「中職強打者的 d 分佈」，不是在 IBB 這裡另開一個聯盟修正項。

`awards.test` 的「累積型門檻依球季場次等比放大」不再嚴格成立——上壘數含整數化的敬遠數，
兩個球季長度各自捨入，殘留千分之二左右的偏差。

## 後續

[ADR 0047](0047-the-league-average-moves-up-the-ability-axis.md) 把所有聯盟的 par 往上搬 2，`reference_par` 因此是 61、中職一軍是 46。這裡寫的觸發線 `d > +6.5` 變成 `d > +4.5`——**觸發的絕對能力沒有動**，變的是它離聯盟平均多遠。除數 180 與「平移量等於權重和」這兩條都不受影響。
