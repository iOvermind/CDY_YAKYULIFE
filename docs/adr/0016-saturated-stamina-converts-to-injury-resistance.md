# ADR 0016: 飽和的體力改換免傷，零點是各守位自己的打滿門檻

## Status

Accepted

## Context

[ADR 0013](0013-stamina-sets-games-played-scaled-on-the-ability-axis.md) 把 `stamina_factor`
訂成錨點表之後，出賽場數那一側在各守位的「打滿」門檻上飽和：DH 55、SS 65、捕手
76.5。門檻之上再練體力，出賽場數一場也不會多。

這在能力軸的上半段留了一段死區。校準樣本的生涯最高 `sta` 是 p50 56、p90 60、
max 64——多數球員的確碰不到 DH 以外的天花板，但只要守位夠好、練得夠久，點數就會
花在一個什麼都換不到的地方。**體力從來不是白練的**，這句話當時只對一半。

傷病那一側原本只看年齡與體質特性（魔鬼筋肉人、帕瓦諾、逃學威龍），與體力無關。
但傷病在這個遊戲裡不是一個獨立的懲罰數字，它決定的是這一季能上場多久，而出賽量
本身就是勝利份額的分母——傷病與出賽場數量的是同一件事。既然如此，飽和的體力沒有
理由不流到這一側。

## Decision

**超過打滿門檻的體力，每一點折抵受傷機率；零點是各守位自己的打滿門檻。**

零點不是一個共同的數字，是由 `staF(sta) × posF = 1` 反解出來的，與出賽場數那一側
共用同一條曲線：

| 守位 | 零點 `sta` |
| --- | --- |
| DH | 55 |
| 1B | 57 |
| LF | 59 |
| 3B / RF | 61 |
| 2B | 63 |
| SS / CF | 65 |
| C | 70（反解是 76.5，見下） |

捕手的反解 76.5 沒有人到得了，那個零點等於不存在。**釘在 `zero_point_cap` 70**——
70 是捕手蹲到 144 場的地方，一個捕手扛得動的滿檔工作量。用「扛滿」代替「打滿」，
是這張表上唯一一個不是純反解的數字。

零點跟著聯盟場數沿能力軸下調，與 ADR 0013 同一套算法：
`40 + (zero − 40) × leagueGames / 162`。中職 120 場的 DH 零點是 51.1。

**折抵有上限，`max_cut` 5，訂在魔鬼筋肉人的 `cap` 10 上。** 基礎 15 折滿正好落在
10：練到頂等於魔鬼筋肉人，但不越過它。體力可以買到那個特性給的東西，不能買到比它
更多的——否則特性就不是特性了。年齡那一項不受影響：35 歲的 27 折滿是 22，仍然遠
高於帶特性的 10。

**斜率 `per_point_above` 0.5，比場數那一側便宜。** 要在門檻之上再練十點才折滿
（DH 55→65、捕手 70→80）。兩種貨幣是同一份體力買的，第二種不該更划算。

**這一項算在年齡之後、體質特性的上下限之前。** 體力是身體的一部分，該待在體質
的上下限裡面；事件卡的 `extraRisk` 才是自找的、不受上限保護的那種。

對稱的另一頭沿用既有行為：體力 40 以下不再少打，改成容易壞（`per_point_below`
0.8，`max_add` 16）。

## Consequences

`sta` 這條軸在 40 到 80 之間全段有用：40 以下換易碎，40–門檻換場數，門檻以上換
免傷。**但兩種貨幣不能同時拿**——過了打滿門檻，多練的每一點只會出現在受傷機率上，
玩家得先決定他要的是哪一種。

蹲捕的免傷比指定打擊難換得多（零點 70 vs 55），這是守位勞損的第二次計價：捕手
在場數那一側已經被 `posF` 0.80 罰過一次，免傷這一側再罰一次。移防因此更划算，
而移防本來就是延長單季出賽壽命的真實手段。

折出來的值取整數。這個數字直接印在健康回報卡上，`受傷機率 10.944389275074478%`
不是一張卡該長的樣子。

`injuryChance()` 因此多收 `stamina` / `position` / `leagueGames` 三個選項，且都是
選填——養成期的業餘傷病與測試裡不涉及體力的路徑照舊只給年齡與特性。`rollInjury()`
與 `game.ts` 的年度健康檢查一併把這三項傳進去。

護欄測試 `scripts/guardrail.test.ts` 的名人堂比例仍紅（17.6%，上限 12%、目標 2%），
那是 ADR 0013 留下的既有紅燈，根因在獎項取得率，不是這一份改動造成的。
