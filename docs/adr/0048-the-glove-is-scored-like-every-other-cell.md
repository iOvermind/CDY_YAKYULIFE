# ADR 0048: 守備分用與成績同一個紀錄錨定的形狀，守位去留改看它

`DEF = 25 × sign(x) × |x / 10|^1.3893`，x 是守備分減該守位當年平均線。守不守得動
一個位置，判準從「守備分 ≥ 硬門檻」換成 `DEF ≥ −10`。

## 背景

### 守 SS 就打不動

大聯盟游擊的門檻是 par + 5，平均線再 + 4。[ADR 0047](0047-the-league-average-moves-up-the-ability-axis.md)
之後那條線是 70，而守備權重 rng .5 / fld .3 / arm .2，要碰到 70 大約要
rng 75 / fld 70 / arm 63。潛力天花板是洗牌分階的——一項 72–80、一項 64–74、一項
56–68、其餘 46–62——那等於把前三階全押在守備，打擊每一項都落在 46–62。

份額那端救不了：游擊的守備責任佔全隊 3%，打擊一個棒次佔 5.6%。守備再好也補不回
打擊，而**即使是游擊，也不可能長期接受 OPS+ 80**。真正的病灶是那條硬門檻：守備
差一分就被掃到三壘，於是「打擊出色、守備平庸的游擊」這個現實中最常見的球員型態
在這套系統裡不存在。

### 練守備幾乎沒有回報

守備側的勝率原本是畢氏公式吃 `守備分 ÷ 該守位平均`。那條比值的幅度極窄：

| 游擊的守備 | 守備勝率 | 滿季的守備勝利份額 |
| :--- | ---: | ---: |
| 剛好守得住 | .471 | 6.87 |
| 聯盟平均 | .500 | 7.29 |
| 能力 80 | .566 | 8.25 |

從勉強守得住到能力全滿，整條區間只有 1.4 個勝利份額；同一段距離在打擊那一側大約
是 7 份。現實的對照是 James 的系統裡頂尖游擊的單季守備份額約為平均游擊的兩倍。

## 決定

**守備分走紀錄錨定的形狀**，與 `season.json` 的每一格一致。兩端釘死：站在同守位
平均線上是 0，高出 `span`（10 分能力）剛好是錨點 +25。中段由次方壓下去，而次方是
反解出來的——守得住的最低標準（平均線 −4，舊門檻的位置）要落在 −7，也就是降守位
那條帶的中間：`ln(7/25) ÷ ln(4/10)` = 1.3893。

**所有守位的錨點都是 +25，依守位縮的是「拿到 +25 需要多少能力」**：游擊 80、
中外野 79、捕手 76、二壘 75、三壘 73、右外野 72、左外野 69、一壘 64。守備需求最高
的游擊剛好要求能力 80，與成績錨點的「納入的每一項都到 80」是同一條線。守位之間的
價值差不在這個數字裡——它在勝利份額的責任占比上（捕手 24、一壘 3），那是 Bill
James 的分工：**份額大小承擔守位價值，守位內部的比較承擔守得好不好**。

夾在 `[−25, +26.25]`。上夾與成績共用同一個語意：靠能力最多拿到錨點的 105%，剩下
留給上限事件推過 80 的怪物。下夾是勝率比值的觸底點。

**平均線兩段合一。** `defense_offsets` 從「守得動的最低門檻」改成「該守位平均相對
par 的位移」（舊位移 + 4），`defense_average.margin` 與 `defense_score_scale` 一併
刪除。門檻不再是判準之後，它只剩下製造平均線這一個用途，而一個沒有人讀得到的數字
遲早會跟它的註解對不起來。

**去留改看 `DEF ≥ −10`。** 舊門檻等於 DEF −7，新線在 −10，換算回能力是平均線
−5.17，比舊門檻寬 1.17 分。那 1.17 分就是這次要買的東西：打擊出色而守備平庸的游擊
可以提著 −8 的守備分繼續站在那裡。

**守備勝率改吃 DEF**：比值 `1 + DEF / 25`。錨點 .800、平均 .500、降守位線 .265。
責任占比仍然乘在外面，DEF 只換掉品質那一項。替代水準從守位門檻改成降守位那條線
——與打擊、投球同一個概念（「剛好還留得住的人」），只是那條線在守備上由降守位的
門檻定義。

## 抖動只進顯示

顯示的守備分乘出賽比重、加 ±5 抖動；去留判定吃**不乘不抖**的純值。

兩件事都有理由。`defense.ts` 的檔首寫著「本模組是純函式，不抽亂數——擲骰決定守哪裡
會讓玩家練了守備卻看不到效果」，那條原則在 DEF 變成判準之後仍然要成立。而如果判定
吃乘過出賽比重的值，傷缺半季的爛守備反而會因為 DEF 貼近 0 而保住位置。

年齡折讓（≤23 歲 −3、≤25 歲 −1.5）與慣用手折扣同理，改成作用在**判定用的平均線**
上，不動顯示的守備分：球團願意為一個 22 歲的游擊手多等兩年，那是去留的事；他今年
守得好不好是另一本帳，不該因為他年輕就變好看。

## 實測

同一組三百顆種子、同一套配點策略：

| | 改之前 | 改之後 |
| :--- | ---: | ---: |
| 有登錄守位的頂級聯盟球季 | 274 | 362 |
| 負 DEF 的球季佔比 | 56% | 70% |
| 生涯總評價分（平均） | 42.0 | 42.9 |

**守得住位置的人多了三成**，而其中多出來的那一批正是負 DEF 的人——那就是這次要
的東西。生涯總分只漲 2%，`tier_thresholds` 不必動。

這份測量有個限制：跑的是「點數平均撒在八項能力」的策略，那種球員在改前改後都站不
上游擊與捕手，因此它量得到的是一壘與二壘那一段。帶天賦的族群要另外量。

## 還沒解的

`defense_average.margin` 的註解本來寫著「暫定值，正式值由校準腳本決定」。合一之後
那段話跟著消失了，但那件事本身還沒做——各守位的平均線應該由模擬量出來的分位數決定，
而不是手寫的位移。要跑 `npm run calibrate`，量實際佔著各守位的球員守備分分布。
