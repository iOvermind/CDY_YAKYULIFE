# ADR 0046: 錨點要求它納入的每一項能力都到 80

成績錨點的定義從「能力 75 的球員打一整季」改成「**能力 80**」。除數因此是
`80 × 權重和`，而每一格的次方乘上 `ln(59/75) ÷ ln(59/80)` = 0.788——那是「讓能力
等於 par 的人維持原值」的封閉解。

## 背景

舊制的基準是 75，而量表上限是 80。**那讓最後五級幾乎是白練的**：比值在 75 就是
1.0，再往上只剩 `ratio_cap` 的 5% 頭空間，於是能力 75 與 80 打出來的東西幾乎一樣
——全壘打 60.4 支對 59.8 支。一個把力量從 75 練到 80 的玩家看不到回報。

## 決定

**基準能力 = 80。** 比值 = `(加權平均能力 − par + 59) / 80`，納入的能力都到 80 就
是 1.0，也就是打到錨點。

**次方全部乘 0.788。** 這不是手調出來的數字，是解出來的：要讓聯盟基準（能力等於
par 的那個人）一分都不動，就得滿足

```
(59/80)^新次方 = (59/75)^舊次方   →   新次方 = 舊次方 × ln(59/75)/ln(59/80)
```

實測驗證：中職一軍的基準 OPS .7035、上壘率 .3183、長打率 .3852、打擊率 .2648、
防禦率 4.29，與搬家前完全相同。**低階門檻沒有動，動的是中段到頂端的那一段。**

**沒有次方的那幾格動它們自己的旋鈕**，判準一樣是「par 那一點維持原值」：被安打的
斜率 0.8 → 0.853、被全壘打的除數 220 → 268.4、盜壘刺的係數 0.2 → 0.213、得分的腿
係數（四個權重同乘 1.067）、打者三振的 offset 112.5 → 120 與除數 134 → 144.6、投手
四壞的控球缺口次方 0.6 → 0.706。投手局數的體力係數本來沒有次方，補了一個 0.788
——否則 par 水準的先發會少投 6%，而那不是這次要改的東西。

**獎項門檻的 d 從 16 變成 21**（= 80 − 59）。門檻線的定義本來就是「達到錨點水準的
那個人」，基準一搬它就跟著搬。

## 錨點是率，不是季總量

這件事容易讀錯，所以寫下來：錨點的單位是**每 600 打數／720 打席**，而滿季只有約
530 打數。能力 80 的球員實測 500 季平均 212.5 安打、57.9 轟，換算回每 600 打數是
239.7 與 65.3——剛好落在錨點上。季總量看起來比錨點低不是曲線沒到位，是分母不同。

噪音與抖動逐季生效，平均之後收斂成 1.0 與 0，所以平均值裡看不到它們。單季的頭空
間仍然在：同一批 500 季裡量到過 242 安打與 72 轟。

## 代價：專才被罰

錨點要求**納入的每一項**都到 80，而專才只有一項到得了。一個只練主力能力的人離錨點
比從前遠：

| 專才（那一項 80、其他 60） | 錨點 75 | 錨點 80 |
| :--- | ---: | ---: |
| 全壘打（權重 con 1、pow 2） | 56.3 | 42.0 |
| 三壘打（pow 1、con 1、spd 4） | 11.5 | 3.9 |
| 安打（con 1、eye 1、spd 0.5） | 202.8 | 192.6 |
| 盜壘（只看 spd） | 78.8 | 75.0 |
| 四壞（只看 eye） | 105.0 | 100.0 |

只看一項能力的格幾乎不受影響——那 5% 是舊制 `ratio_cap` 的頭空間。真正的受害者是
權重裡含有「別人的能力」的格：純長打者掉 25%，純快腿的三壘打掉 66%。

**這是刻意接受的**：想打到錨點就不能只練一項。反過來說，全才的回報從此有五級的空
間可以長，而那正是搬家的理由。

## 三壘打是例外：它的次方不由 par 解

par 水準的人一年只有 0.1 支三壘打，拿那個點當基準沒有意義。這一格的判準是形狀——
**腳程 80 的比值要是腳程 70 的五倍以上**（其他能力 60），反解出次方 ≥ 16.89，取
17.5。它因此是全表唯一不吃 0.788 那條規則的格。

它的產量仍然掉了（純快腿 11.5 → 3.9 支）。那條線走不掉：底數從 0.978 掉到 0.917
之後，要保住產量得把次方降到 5.16，而那會讓「跑得中上」的人開始一年五六支——現實
裡那一段幾乎沒有。**保形狀還是保產量，兩者只能選一個**，這裡選形狀。
