# ADR 0027：季末先問外面的世界，再談自己的合約

## 背景

季末流程原本的順序是：

1. `#contractPhase` — 母隊續約／延長合約／自由球員
2. `#endOfYearChoices` → `#scouting` — 海外球團的挖角與入札
3. `#demotionOffers` / `#retirementChoices`

這個順序讓玩家在還不知道外面有沒有人要之前，就得先回答母隊「要不要簽」。
等到簽完約才看到海外報價，那些報價已經沒有意義——合約在前一步就鎖住了。
回報 #26 描述的正是這個經驗：挖角與入札的問句永遠來得太晚。

## 決定

季末的詢問順序改成「先外後內」：

1. `#seasonLedger` — 年資、球團年資、合約年限的記帳（純結算，不問玩家）
2. `#endOfYearChoices` → `#scouting` — 海外挖角與入札；玩家可能在這裡就換了球團
3. `#contractTalks` — 只有在玩家仍留在原球團時才談續約
4. `#demotionOffers` / `#retirementChoices`

原本的 `#contractPhase` 拆成兩半：記帳的部分（`#seasonLedger`）必須在升降級判定之後、
所有詢問之前跑完；談判的部分（`#contractTalks`）延到挖角結束之後。

`#scouting` 若導致 `#moveTo`，球團已經換人，`#contractTalks` 就會被跳過——
新球團的合約由 `#moveTo` 自己給。判斷方式是比對 `#scouting` 前後的 `pro.team`。

## 後果

- 玩家看到的順序符合真實的季末：先知道市場行情，再決定要不要留下。
- 海外報價第一次真的有機會影響結果。
- 續約的談判基數（年資、球團年資）在 `#seasonLedger` 就固定了，
  不會因為中途換隊而算到新球團頭上。
- 測試 `海外球團遞出合約問在母隊續約之前` 守住這個順序：
  在「海外球團遞出合約」之前的卡片標題裡不得出現續約／解約／合約／贈約。
