# ADR 0012: 外籍加成只在球團主動時成立

## Status

Accepted

## Context

`import_premium`（4 分）的理由寫在 `leagues.json` 裡：外籍名額有限，球團得證明
簽這個人比用本地人好，所以外籍球員要多 4 分才落得下去。

這個論證預設了**球團在挑人**。但同一個加成被無差別地套在 `landingLevel()` 的
所有呼叫點上，包括 `fallbackOffers()`——被釋出、被下放的人自己去找容身之處的
那條路。那裡的處境是相反的：澳職球團面對一個從大聯盟掉下來的人，替代人選不是
本土明星，是沒有人。

後果是退路被封死。加上 4 分之後（`min - 3` 的實際下限對上 `min + 4` 的門檻，
X 要能落到 Y 得滿足 `min_Y ≤ min_X - 7`），下放與釋出的可達矩陣是：

| 從 | 墨聯 | 澳職 |
| --- | --- | --- |
| 大聯盟 | ✓ | ✓ |
| 日職一軍 | ✓ | ✓ |
| 韓職一軍 | ✗ | ✓ |
| 中職一軍 | ✗ | ✗ |
| 墨聯 | — | ✗ |

墨聯的 `min` 45 只有大聯盟下放（49）能貼著擦過，澳職的 38 也低於中職一軍的
41。而 `fallbackOffers` 的註解寫著「墨聯與澳職只出現在這條路上，那正是它們的
價值」——它們的唯一入口被自己的門檻擋住了。實測 400 局裡玩家只從大聯盟掉進去
過，其餘體系的人直接退休。

## Decision

外籍加成由**誰主動**決定，不由體系決定。新增 `Approach`：

- `recruit`——球團上門找你。挖角、入札、自由市場。加成成立。
- `seek`——你上門找容身之處。釋出與下放的尋路。加成為 0。

`importPremium()` 在 `seek` 時回傳 0，`landingLevel()` 與 `topLandingBar()` 一
併吃這個參數（兩者必須同調，否則簽約金的 d 值會對不上落地層級）。

`fallbackOffers()` 預設 `seek`——那是它的主場。**自由市場是例外**：它借用同一
份名單，但 FA 問的是「誰想要你」，球團仍在挑人，所以 `#faMarket()` 明確傳
`recruit`。這個例外寫在 `FallbackContext.approach` 的文件上。

## Consequences

拿掉 4 分之後，同一張矩陣變成：

| 從 | 墨聯 | 澳職 |
| --- | --- | --- |
| 大聯盟 | ✓ | ✓ |
| 日職一軍 | ✓ | ✓ |
| 韓職一軍 | ✓ | ✓ |
| 中職一軍 | ✗ | ✓ |
| 墨聯 | — | ✓ |

墨聯成為日職與韓職的退路，澳職成為中職以上所有體系的退路。韓職一軍 46 對墨聯
45 是貼著過的——那是刻意的，退路本來就該勉強。

**校準沒有動。** 分級分佈與建議門檻在改動前後一致（246/220/153/65〜66，評價分
p50 99），生涯長度中位數不變。這條路只影響少數真的走到那裡的人，不是系統性的
延壽。

沒有動 `leagues.json` 的任何數字。這是個判斷規則的錯誤，不是校準問題——先前把
它當成門檻太高，如果改 `min` 會連帶動到挖角與入札，那些地方的 4 分是對的。
