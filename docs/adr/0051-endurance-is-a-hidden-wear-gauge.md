# 0051. 耐力是看不見的磨損量表，不是另一種體力

日期：2026-09-24

## 狀態

已接受

## 背景

「捕手蹲到三十幾歲就蹲不動」「先發投到某個年紀就該開 TJ」在遊戲裡一直沒有機制，只能靠年齡衰退間接表達——而年齡衰退對每個守位一視同仁，於是捕手與一壘手老得一樣快。詞彙表裡早就寫了一個「TJ 量表」，特性〈橡膠果實〉也掛著「TJ 量表上限翻倍」，但兩者都沒有實作。

## 決策

**耐力是一個獨立的、看不見的存量**（issue #17–#23）：

- 野手與投手各一池，開局各擲 80–100。野手照守位與出賽磨（捕手最兇、指定打擊不磨），投手照局數磨，每季再乘一個 0.5–1.5 的係數；每季自然恢復一點。二刀流兩池分開算。
- **玩家看不到數字**，只看到狀態字（充沛、疲勞、透支、耗盡），掉階或回升時發一張卡。
- 野手耗盡照樣守得了，守不守得住仍由守備分決定；代價是守備三項逐季下滑（獨立於年齡衰退、量約七成）。狀態每掉一階，守位會議問一次要不要退守，拒絕之後同一階不再問。
- 投手耗盡時季前問要不要開 TJ：開＝整季復健、隔季回到八成；不開＝**七傷拳**，每撐一季受傷機率在 95% 的夾子之外再累加 20，投球能力下滑；**天賦前**機率滿 100% 就報銷、記大傷、強迫開刀。
- 「TJ 量表」就是投手那一池，不另做一套。

## 後果

- 守位終於有了壽命：校準到捕手約 32–34 歲耗盡、游擊與中外野晚幾年、一壘幾乎撐到退休。
- 退守是玩家的選擇而不是系統的判決——那與守位系統「守不動才降」的立場一致：耐力管的是代價，守備分管的是資格。
- 七傷拳的 100% 看天賦**之前**的機率，因此〈金剛不壞〉之類的天賦拖不住那一刀；拖得住的是〈橡膠人〉〈配速大師〉與〈橡膠果實〉，它們作用在耐力本身。
- 抽取順序改變（開局多擲兩池上限、每季多擲兩次係數），舊的重播日誌不能重現——引擎版本 8 尚未發佈，不另跳號。

## 替代方案

- **把耐力做成看得見的數字。** 玩家會開始精算「還能蹲幾季」，而現實裡沒有人知道自己的膝蓋還剩多少；狀態字保留了不確定性，又給得出足夠的訊號。
- **耗盡就強制移防。** 那會讓耐力變成第二條守位門檻，與守備分打架；改成「照樣能守、但會掉」，兩條線各管各的。
- **七傷拳的 100% 看最終機率。** 降受傷率的天賦就能無限期拖延開刀，「打針硬撐」會變成沒有盡頭的選項。
