# ADR 0005: 投手評價依角色走兩套權重，並吃一道角色折扣

## Status

Accepted

## Context

投手與野手的綜合能力長期不對稱。用同樣的加點總額（八項能力都從 20 起跳、共加
200 點）量出來：

| 建構 | 綜合能力 |
| --- | --- |
| 投手：球速／控球／橫向變化／體力各 70（三項變化球留在 20） | **70.0** |
| 野手：擊球／力量／選球／速度各 70（守備四項留在 20） | 游擊 **55.0**／一壘 64.0 |
| 野手：八項平均各 45 | 游擊 **45.0** |

原因是兩側的公式結構不同：

```
pitcherRating = 六項投球能力取「前三名」加權(.42/.30/.18) + 體力 .10
fielderRating = 打擊四項「全部」加權(.38/.27/.20/.15) × (1−守位權重)
              + 守備分 × 守位權重
```

投手可以**免費丟掉三項能力**，野手一項都丟不掉——守備還依守位權重壓進綜合裡。
更難看的是極端解：只練球速與控球、零變化球的投手綜合能力是 **74.4**，比任何
野手建構都高，而現實裡那種投手連輪值都進不去。

後果不只是數字難看。綜合能力是**落地層級、挖角門檻、薪資、選秀評估**的共同輸入，
因此校準報表裡（`CALIBRATE_POLICY=pitcher`）投手能打進大聯盟 466 段生涯，
balanced 策略的野手則一段都沒有。

同一時間，投手定位只分先發與後援，判定是「體力 d ≥ −2 **且** 控球 d ≥ −4」。
中繼與終結者沒有區別，`awards.json` 因此留了一句 `_missing_note`：中繼王做不了，
因為中繼成功（HLD）與中繼投手的定位兩者都不存在。所有後援投手一律拿救援成功，
而且永遠 0 勝 0 敗。

## Decision

**1. 四項變化球全部採計，排序後幾何遞減 ×0.5。**

不做「算不算一種球」的離散判定——野手側沒有那種閘門，投手側也不該有。四項變化球
（橫向變化、縱向掉落、變速下沉、特殊奇招）排序後給 `.267 / .133 / .067 / .033`，
多練一顆永遠不會白費，但第四顆只值第一顆的 12%，「一顆決勝球」的味道保留下來。

球速與控球改為固定採計，不再參與「取前三」的競爭——**那是每個投手都要的基本功，
不是可以拿去交換的選項**。

實測結果：集中型建構 70.0 → 58.3，零變化球的火球男 74.4 → 52.0。

**2. 綜合能力依角色走兩套權重，與野手的守位同構。**

```
先發 SP：球速 .25  控球 .15  體力 .10  變化球 .50（.267/.133/.067/.033）
後援 RP：球速 .35  控球 .15  體力 .05  變化球 .45（.240/.120/.060/.030）
```

`fielderRating(ability, position)` 早就是這個形狀——守備權重游擊 .30、一壘 .12，
同一組能力在不同守位算出不同的綜合。投手改成 `pitcherRating(ability, role)` 完全
同構，而且這是**「他不適合先發，但當終結者很好」唯一能被表達出來的方式**。

尚未定位時（養成期、選秀）取兩者較高——與二刀流取投打較高者同一個邏輯，球探本來
就是照你最適合的角色估價。

**3. 後援吃一道角色折扣。**

責任額由角色決定，能力再高也補不回來。實測（中職一軍，par 52）：

| | 局數 | 勝利份額 |
| --- | --- | --- |
| 先發型（體力55 球速55 控球55 變化55） | 149 | **9.9** |
| 後援型（體力35 球速70 控球50 變化55） | 65 | 4.4 |
| 後援型（體力35 **球速85** 控球60 變化65） | 65 | **5.7** |

把球速拉到 85、變化球也練好，後援的份額仍然只有先發的 58%。若不折扣，後援的
權重表（球速 .35、體力只有 .05）會讓低體力的火球男一掉進牛棚綜合能力反而**上升**，
落地層級、薪資與挖角全部高估他。

折扣的形式與指定打擊同構——指定打擊拿一壘手的守備分再扣 12。數值由校準決定，
目標是**評價相等的先發與後援打出相等的勝利份額**。

**4. 先發的分界是體力，加上一條掛在球隊戰力上的輪值線。**

控球那一關拿掉。體力是絕對的生理條件——撐不了一百五十局就是撐不了，跟同年度有沒有
別人更強無關，因此維持固定 d 值門檻，不用「當年聯盟線」。

但先發位置是稀缺的（一隊十三個投手只有五個輪值位置），所以體力過關之後還要擠得進
輪值，而**輪值線掛在球隊戰力上**：強隊 .600 難擠、弱隊 .400 容易占。引擎沒有隊友
名單，但球隊戰力表本來就存在，直接拿來當同隊水準的代理。「在爛隊當先發、去強隊
只能進牛棚」因此不必另外寫。

**5. 牛棚分決定終結者，用當年聯盟線。**

```
牛棚分 = 球速 .50  控球 .25  變化球 .25
```

一局的工作，用力塞進去就對了，因此球速為主。高於**當年的聯盟終結者線**就接下關門的
位置——與單項王同一套「當年那條線」的模型，稀缺性自動成立：一隊只有一個關門人，
強聯盟的線高，旅外之後從關門人變成中繼是自然發生的。

**6. 所有成績欄位掛在主數據上，新增中繼成功。**

主數據是原子：投手是出賽數與局數，打者是出賽數與打席。其餘欄位一律由它導出，**沒有
任何欄位自己擲點數**。既有程式碼大致守住了這條，但牛棚有兩個破口，一併修掉：

```
終結者 SV  = 後援出賽數 × 機會率 × 成功率
中繼   HLD = 後援出賽數 × 機會率 × 成功率
兩者   W/L = 後援出賽數 × 後援決勝率     ← 原本後援永遠 0 勝 0 敗
先發   W/L = 先發場次   × 先發決勝率
```

原本 `role === 'RP'` 就發救援成功，中繼投手因此人人都是關門人。

**7. 中繼王與生涯中繼里程碑一併補齊，救援王改為終結者專屬。**

中繼投手打一輩子拿不到任何獎，那是評價上的空白而不是真實。

## Considered Options

**六項取前五，只縮小免費空間**——改動最小。否決原因：仍然保留「有一項可以完全不練」
的結構，而問題正是那個結構；而且沒有把球速與控球定位成基本功。

**保留取前三，另加球種數的懲罰**——懲罰看得見、好向玩家解釋。否決原因：多一個要
校準的旋鈕，而且需要定義「算不算一種球」的離散門檻——野手側沒有那種東西，投手側
硬加一個會讓兩邊的心智模型分岔。

**單一套權重，角色只影響出賽與成績**——玩家看到的數字不會因為換角色而跳動。否決
原因：「他不適合先發，但當終結者很好」就無處表達，而那正是這次要處理的事。

**兩套都算、對外取較高者**——不會因為被趕進牛棚而身價暴跌。否決原因：很難解釋為什麼
他的數字沒跟著角色走；而且它會讓角色折扣失效——低體力火球男永遠用後援那套報價。

**後援不折扣，出賽量的差別交給成績與評價分反映**——少一個旋鈕。否決原因：綜合能力
是**事前**的輸入（落地、薪資、挖角都在成績出來之前就用它），事後的份額修正不回來。

**輪值線用當年聯盟線**——與終結者同一套邏輯，概念最一致。否決原因：體力是絕對的
生理條件，用相對線會讓弱聯盟裡體力很差的人也能先發，而那不是體力這個屬性的意思。

**生一份輕量的同隊投手名單來排名次**——最寫實，而且「被年輕人擠出輪值」講得出來。
否決原因：新增一個子系統，而球隊戰力表已經足以代理同隊水準。名單留給日後。

## Consequences

**正面**

- 投手與野手的綜合能力回到同一個量級（58.3 對 55.0），落地、薪資、挖角的跨側偏誤
  一起消失。
- 「零變化球的火球男」不再是最優解，而練第四顆球第一次有意義。
- 中繼／終結者第一次有區別，`awards.json` 的 `_missing_note` 與 ROADMAP 的「投手
  定位細分」一起收掉。
- 後援投手第一次有勝敗，中繼投手第一次有欄位可記。
- 投手的角色相依與野手的守位相依變成同一個形狀，兩側的心智模型收斂。

**負面**

- **所有與投手綜合能力有關的校準全部作廢**：分級門檻（剛校準好的 229／182／152／75）、
  落地層級的實際分佈、薪資的量級。新增中繼王還會推高明星帶——獎項有保底規則。
  校準必須重跑，而且要跑 pitcher 策略。
- 綜合能力變成角色相依之後，同一個人的數字會逐年跳動（角色每季重判）。介面上必須讓
  玩家看得出來「這個數字是以什麼角色估的」，否則會被當成 bug。
- 角色折扣是一個新的要校準的旋鈕，而它的校準目標（評價相等 → 份額相等）需要跨角色的
  樣本，比單一分佈的校準麻煩。
- `PitchingLine` 新增 `holds` 欄位，成績列、逐年表、通算表、里程碑、成就櫃都要跟著動。
- 修完之後投手仍比野手高約 3 分（58.3 對 55.0）。決定先接受，留待校準時再看要不要收。

---

> **後續：牛棚擴成三階，定位改為登錄制。**
>
> 這則 ADR 記的是三種角色（先發／中繼／終結者）的年代。後來牛棚拆成**終結（CP）、
> 布局（SU）、中繼（MR）**，加上一個吃下所有落選者的**長中繼（LR）**，判定改成
> 「體力先決 → 實力對聯盟 par 的比值分級」。
>
> 連帶三件事：
>
> - **牛棚分留著**，第 5 點那條規則原封不動，只是它現在分的是三階而不是兩階：
>   對照當年聯盟 par 的比值（終結 105%、布局 102%、中繼 97%）。它問的仍然是
>   「他適不適合關門」，與投手評價問的「他有多好」是兩個問題。
> - **比對用的是原始能力，不是折過的評價。** 角色折扣（第 4 點）仍然存在，但它回答
>   的是身價，用在升降與留隊那一側。拿折過的評價跟聯盟 par 比大小，CPBL 的牛棚線
>   會沒有人構得到，整個牛棚被判成長中繼；折過的評價拿去算自責分，終結者的防禦率
>   會比 par 先發還差。成績與定位判定因此走原始能力（`pitcherStuff()` 與
>   `bullpenScore()`），折扣只留給身價那一側。
> - **救援王不再是終結者專屬。** 救援與中繼改成各定位一組係數——比賽情境不由投手
>   決定，終結者偶爾也拿中繼。
>
> 另外，定位從「每季重判」變成**每季在定位會議上登錄**：往下不問、往上要問、同一個
> 定位上拒絕過就不再問（與守位會議同一套規則，見 ADR 0037）。上面「負面」那條
> 「同一個人的數字會逐年跳動」因此有了出口——玩家自己按下了那一次異動。

## 後續：武器庫改成一組式子取最高分

分組權重（取前 n 名套第 n 組、每組加總為 1）在 2026-09-21 換成六條完整的式子。
形狀是同一個——**球速與控球固定採計、變化球排序後取前 n 顆、全算過取最高分**
——換的是它怎麼把「其餘的球」算進去：

```
(球速 + 控球 + 前 top 顆變化球) / (2 + top) × core + 其餘變化球的平均 × rest
```

先發四式（top 1–4，core 0.85／0.90／0.95／1.00），後援兩式（top 1–2，core
0.90／1.00），`core + rest` 恆為 1。長中繼兩套都算過取高的——他既可能是撐局數
的先發備胎，也可能是多投一局的牛棚手。

**刻意翻過來的一件事：深度現在有回報。** 舊式子裡每組權重加總為 1，所以同水準
的第四顆球不加分；新式子讓「球速控球普通但四顆球都不錯」的技巧派靠最後那一式
拿到最高分（五項 62 的人 56.7，勝過兩項 70 的 52.7）。而一顆決勝球的火球男仍然
落在第一式，並且在後援那把尺上分數更高——先發要把打線輪三次，球種齊是真的值錢。

角色折扣（後援 19）與「控球不參與排序」兩條都沒有動。
