# ADR 0011: 戰力外的下限不吃聯盟浮動

## Status

Accepted

## Context

聯盟水準是逐年浮動的（見 `league.ts`）：`leagues.json` 的 `par`／`min` 是基準值，
每年由體系的位移與貧富差距推導出當年的實際值。升降級判定用當年值是對的——今年
人才斷層就該比較好卡位，那正是浮動要製造的手感。

問題出在戰力外用了同一組數字。浮動的 `min` 會跟著衰退的球員一起往下沉，等於每年
都幫他把及格線調低。中職二軍的基準 `min` 是 30，但浮動範圍是 26.2 ~ 33.4；再減去
`release.margin` 3，最鬆的年份戰力外線會掉到 23.2。加總是近 7 分的緩衝。

實測的後果是球員能力掉到二軍基準線下四五分還賴得住，一路撐到四十歲才收山——
「被扣分到連中職都有困難才退休」。

還有第二個放大器：`#moveTo` 以前無條件把 `yearsAtBottom` 歸零。戰力外轉隊等於每次
再送滿一次寬限期，六個體系就能讓一個早該收山的人一直再拼一年。

## Decision

**升降級用當年浮動值，戰力外用 `leagues.json` 的基準 `min`。**

聯盟今年鬆一點可以保住你的位置，但不可能讓一個低於基準線的人無限期留著。浮動的
意義是「卡位的難易度」，不是「這行的最低及格標準」——後者是這個運動本身的下限，
不該隨景氣移動。

`release.margin` 維持 3，所以實際的線是基準 `min` 減 3（中職二軍 = 27）。保留這段
模糊帶是刻意的：邊緣人還有一點靠聯盟賞飯吃的空間，只是空間不再逐年膨脹。

**`yearsAtBottom` 不因換體系歸零。** 它量的是「連續在最低層級掙扎了幾季」，那是球員
的狀態，不是球團的帳。落腳在底層以上才算真的重新站穩，那時才歸零。

跌破線之後的處置是強制的，不擲骰：`#fallback` 有更低的聯盟就開邀請，`landingLevel`
擋掉能力不夠的體系，全部落空就直接引退。

## Consequences

各體系最底層的戰力外線從此是固定值：

| 底層 | 下限 | 戰力外線 |
| --- | --- | --- |
| 中職二軍 | 30 | 27 |
| 韓職二軍 | 36 | 33 |
| 澳洲棒球聯盟 | 38 | 35 |
| 新人聯盟 | 39 | 36 |
| 日職二軍 | 44 | 41 |
| 墨西哥聯盟 | 45 | 42 |

生涯長度的中位數不受影響（p50 仍是 17 年、退休 33 歲）——這條線本來就不該咬得到
上得了一軍的人。它咬的是二軍收場的那四分之一。

`standards` 參數對 `evaluateMovement` 的 release 分支不再有作用。讀這段程式時會覺得
奇怪「為什麼這裡不用當年的值」，這份 ADR 就是給那個瞬間的答案。

LMB 與 ABL 是單層聯盟，既是頂級也是底層，因此墨西哥的戰力外線（42）比日職二軍
（41）還高——你可以在日職二軍賴著，卻會被墨西哥掃地出門。這個排序是 `leagues.json`
的 `min` 直接推出來的結果，不是特例，但值得記著。
