# ADR 0036: 一階只有一個名字

生涯累積數據（500 安打、2000 三振）同時出現在兩個地方：成就櫃的「累積」格，
和生涯里程碑卡。兩邊爬的是同一座階梯——同一個 `ladderTop()`、同一份級距、
同一套分數——但名字原本是各寫各的：成就櫃 `joinName(label, name, top)` 排成
「中職 安打 500」，里程碑卡 `` `${highest} ${spec.name}` `` 排成「500 安打」。

同一件事長成兩個樣子，玩家得自己猜那是不是同一件事。

## 決定

階名只有一個來源：`rungName(top, name)`，數字在前——「500 安打」是一句話，
「安打 500」讀起來像另一個欄位的數值。成就櫃在前面接聯盟前綴，里程碑卡直接用。

`career.ts` 從 `achievements.ts` import `rungName`，跟它早就共用的 `ladderTop`
走同一條路。

由 `achievements.test.ts` 的「成就櫃和里程碑卡的階名是同一份」釘住：兩邊拿同一
筆數據，成就櫃的名字必須以里程碑卡的名字結尾。

## 範圍

只管名字的寫法。門檻誰算幾階（生涯從第 2 階起算、聯盟從第 1 階）不變，
生涯累積只算頂級聯盟也不變——那是 `summarizeCareer` 用 `topTotal` 決定的，
與這裡無關。
