# ADR 0037：一套守位系統走遍三個階段，降沒有選擇，升可以拒絕

## 狀態

已採用。取代 [ADR 0021](0021-defense-thresholds-borrow-the-top-league-ruler.md)
第 2 點的「暫定守位」。該 ADR 的其餘三點（門檻借頂級聯盟的尺、純投手在養成期
掛 DH、出賽勞損與守備分吃這個位置）全部保留。

## 背景

守位在這個專案裡長成了三套不同的東西，而且沒有一套是玩家選的那個。

**legacy 只在頂級聯盟開守位會議。** `index_legacy.html` 的 `dposReview()`
第一行就是守門條款：`if(S.stage!=='PRO'||!(S.lv==='CPBL1'||...)){ cont(); return; }`。
養成期與二軍根本沒有守位系統，`S.dpos` 一直是 null。而 legacy 的開局只讓玩家
選**四個粗分類**——投手／捕手／內野手／外野手。「你選內野手，教練把你登錄為
游擊手」在那裡毫無矛盾，那正是「內野手」這個詞的意思。

**新版把開局選項細化成九個具體守位**（`abilities.json` 的 `start_positions`），
卻沿用了同一套掃描。`scanListFor()` 的內野光譜是 `[SS, 2B, 3B, 1B]`，**從游擊
開始掃、取第一個守得動的**，`1B` 永遠是最後一個候選。於是選一壘手開局的人：
守備還行就被登錄成游擊手，守備不行就掉到 DH——**畫面上幾乎不可能出現「一壘
手」**。入學卡寫的守位在養成期必然被蓋掉（`docs/problems.txt` 的 U5 回報）。

**ADR 0021 又把推導擴張到了養成期與二軍**，形式是「暫定守位」：每次讀取都現算、
不登錄、不發卡、不經玩家同意。它解決了「二軍是守備免罰區」，但也讓守位變成一個
每年會自己漂移、玩家從未被詢問過的欄位。ROADMAP 的「二軍出賽數會因暫定守位而
漂移」就是它的直接後果——出賽勞損吃的是一個每次讀取都可能不同的值。

三件事疊起來的結果是：**守位是這個遊戲裡玩家唯一親手選過、卻從來不算數的決定。**

## 決定

**一套系統，三個階段通用。** 登錄守位從養成期第一年就存在，二軍與一軍延續同一份
登錄，不再有「離開頂級聯盟就撤銷登錄」。`#fieldPosition` 的現算路徑（暫定守位）
移除——守位只有一個來源，就是登錄值。

**首次登錄＝玩家選的起始守位。** 不掃描、不覆蓋、不發卡：入學卡已經說過他是什麼
守位，再發一張只是重複。唯一的例外是 **UTIL（守位不定）**——他沒有本位，兩條光譜
都掃、取守得動的最高階，並發一張「守位登錄」卡告知結果。那正是他選 UTIL 的意思：
你幫我決定。二刀流的起始守位必定是 UTIL（[ADR 0009](0009-start-position-locks-ability-side.md)），
因此走的是同一條路。純投手不進這個系統（[ADR 0021](0021-defense-thresholds-borrow-the-top-league-ruler.md) 第 3 點）。

**光譜與掃描邏輯不動**：`SS→2B→3B→1B`、`CF→RF→LF→1B`、`C→1B`，掃不到補 `DH`。
掃描永遠取守得動的最高階，**因此升降都能跳階**——游擊退到連三壘都吃力就直接去
一壘，狂點守備也可能從一壘一次升回游擊。

**動的是話語權，而且升降不對稱：**

- **降守位不給選擇**，發卡告知。守不動就是守不動，那不是一個可以商量的事實。
- **升守位要問**，同意或拒絕。往上是機會不是判決，而且它有代價——更吃重的守位
  意味著更高的門檻，明年可能就守不住了。
- **兩者都不給「要守哪裡」的選擇**。位置由守備能力決定，玩家決定的是要不要動。

**拒絕記憶掛在當前登錄守位，守位一有變動就整組清空。** 在 1B 拒絕過升 2B，只要
還在 1B 就不再問 2B；掉到 DH、或升到 3B，那份記憶立刻作廢，2B 會重新問一次。
記住的是「我在這個位置上做過的決定」，不是「我這輩子拒絕過什麼」——離開了那個
位置，當初拒絕的理由也就不在了。

## 後果

- **入學卡不再說謊。** 選一壘手就是一壘手，守備練起來之後會收到一張問你要不要
  升游擊的守位會議卡，你可以說不要。
- **二軍出賽數的漂移消失。** 出賽勞損吃的是登錄值，而登錄值只在守位會議上改變，
  不再每次讀取都重算。ROADMAP「最後批次」的那一條隨之關閉。
- **職業第一年會出現一波降守位卡。** `#benchmarkLevel` 在畢業那年從學制階段的 par
  換成體系頂級聯盟的門檻（ADR 0021 第 1 點保留），尺突然變嚴。那在敘事上是對的
  ——高中的游擊手守不動職業的游擊——但它會是這次改動最顯眼的變化。
- **守位會議變成一個每年都可能出現的節點**，位置在季初訓練之後、事件卡之前，
  養成期與職業期同一個節點。`stay` 不發卡，所以沒有變動的年份仍然安靜。
- 存檔是重放日誌（[ADR 0002](0002-deterministic-rng-and-replay-log.md)），選項的
  意義變了，`ENGINE_VERSION` 要滾——升守位是一個新的可回答選項，舊日誌的選項序號
  對不上（[ADR 0032](0032-a-die-spends-its-face-a-point-buys-a-level.md) 立的規矩）。
