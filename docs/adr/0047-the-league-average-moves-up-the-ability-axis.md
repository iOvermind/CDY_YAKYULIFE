# ADR 0047: 聯盟平均往能力軸上搬 2，買回次方的空間

所有聯盟的 `par` 與 `min` 一律 +2，`reference_par` 因此是 61。每一格的次方乘上
`ln(59/80) ÷ ln(61/80)` = 1.12294——那是「讓能力等於 par 的人維持原值」的封閉解，
與 [ADR 0046](0046-the-anchor-asks-for-eighty-on-every-ability-it-counts.md) 那次
乘 0.788 是同一招。

## 背景

**全壘打那一格的次方被護欄卡死了。** 聯盟平均 OPS 的地板是 .700，而護欄看的是
「能力等於 par 的那個人」。他的底數只跟 `reference_par` 有關、與聯盟無關：比值
`(能力 − par + reference) / 80` 在 d = 0 時就是 `reference / 80`，par 在裡面約掉了。
聯盟平均釘在絕對能力 59 的時候那個底數是 0.7375，次方拉到 6.37（未乘 0.788 的尺）
就把 OPS 壓到 .7035，6.47 直接破底。

彎度是兩端釘死之後唯一還能調的東西，而它調不動了。後果是**中段太漂亮**：大聯盟
能力 70 的球員拿到錨點的 42.7%、75 拿到 66.3%，破紀錄的人並沒有被壓在 75–80 那
一段裡。

## 決定

**把聯盟平均沿著能力軸往上搬 2。** 這不是「讓玩家變弱」的改動，是換護欄的著力點：
同一條比值曲線，聯盟平均從絕對能力 59 挪到 61，底數從 0.7375 升到 0.7625。同樣的
聯盟平均 OPS 從此由更陡的次方產生。

`reference_par` 必須跟著搬。它的定義就是「大聯盟的 par」，那條性質（大聯盟就是表面
數字、低階聯盟自動下修）靠的是 `par − reference_par`，兩者同步移動這一項才維持 0。
比值對**同一個絕對能力**因此一分不變——動的只有護欄站在曲線的哪一點上。

**次方全部乘 1.12294。** 解出來的，不是調出來的：

```
(0.7625)^新次方 = (0.7375)^舊次方   →   新次方 = 舊次方 × ln(0.7375)/ln(0.7625)
```

兩端因此都釘死：聯盟平均 OPS 仍是 .7035，能力 80 仍然剛好打到錨點（1 的任何次方
都是 1）。掉下來的是中段——大聯盟能力 70 從錨點的 42.7% 到 38.5%，75 從 66.3% 到
63.0%。

**沒有次方的那幾格動它們自己的旋鈕**，判準一樣是「兩端維持原值」：被安打的基底與
斜率 1.4／0.853 → 1.490／0.943、被全壘打的兩個錨點 10／35 → 9.561／38.684、盜壘刺
的係數 0.38／0.213 → 0.402／0.236、打者三振的 offset 120 → 110.857 與除數 144.6 →
130.829、投手四壞與觸身的控球 span 60 → 54.286、被長打的球威斜率 0.1 → 0.111、投手
局數的體力次方 0.788 → 0.885。得分的腿係數只有一個旋鈕釘不住兩端，改成吃同一個
次方——腳程 80 那一點本來就是 1.0，次方咬不動它。

**獎項門檻的 d 從 21 變成 19**（= 80 − 61）。門檻線的定義還是「能力 80 的那個人」，
絕對難度一分沒變。敬遠的觸發線從 d > +6.5 變成 d > +4.5，同理：觸發的絕對能力沒變，
變的是它離聯盟平均多遠。

**生涯難度的零點 `baseline_par` 從 44 搬到 46。** 它取的就是中職一軍的基準值，聯盟
動了它就得動，否則所有人的生涯評價分會同乘 `(46/44)^exponent` 隱形通膨。

## 三壘打是例外

它的彎度由形狀決定而不是由 par 決定——par 水準的人一年只有 0.1 支，那個點沒有東西
可以釘。這一格因此連兩次搬家都不吃係數，理由與 ADR 0046 寫的同一條。

## 代價：d 全面少 2，不補償

同一個絕對能力的球員，成績單一分不動，但他離聯盟平均近了 2 分。吃 d 的判定照單
全收：打席基數（`at_par` 4.15 + 每點 0.022，因此少 1.1%）、守備分（加權能力減該守位
平均）、明星線、球隊戰績貢獻、自由球員上門的球隊數、國家隊的 `min_d`、合約年限的
perf 映射、業餘大賽的強弱比較，以及 `min` 帶來的降級與戰力外風險。

**這是刻意不補償的**：聯盟真的變強了，站不站得住本來就該跟著變難，補回去會讓這套
邏輯跟舊的對不上。

幅度是量出來之後收斂的。先試過 +3，三百條生涯的實測是「上過頂級聯盟」從 188 條掉到
110 條、平均頂級聯盟年資從 5.89 季掉到 2.58 季——那不是「稍微難一點」，是把大部分
生涯留在二軍。`min` 是其中的元凶：同樣 par +3 而 `min` 不動的話，年資回到 6.06 季。
收成 +2 之後既有的生涯測試全數回到綠燈，只有「老將還在談約」那條罕見路徑的掃描範圍
要從 150 顆種子拉到 400 顆。

## 還沒解的

**守備分在高聯盟幾乎不可能是正的。** 大聯盟游擊的門檻是 par + 5，平均線再 + 4，
搬家之後是 70。守備權重 rng .5 / fld .3 / arm .2 要碰到 70 大約要 rng 75 / fld 70 /
arm 63，而潛力天花板是洗牌分階的（一項 72–80、一項 64–74、一項 56–68、其餘 46–62）
——那等於把前三階全押在守備，打擊每一項都落在 46–62。份額那端救不了：游擊的守備
責任佔全隊 3%，打擊一個棒次佔 5.6%。

這一格要改成與其他算式同一個形狀（三項守備能力都到 80 時 DEF 錨點 +25，乘噪音加
±3 抖動，可為負，落在 −5 到 −15 觸發降守備位置），但那需要先有校準數據，而那份數據
必須是這次搬家之後量的。另開議題處理。

## 後續：聯盟平均 OPS 不再是 .7035

2026-09-21 把全壘打錨點的分母從 600 打數改成 500——現實的單季紀錄（73 支）是在
476 打數裡打出來的，會打到那個量的人同時也被保送到沒有打數可打。聯盟平均的長打率
因此從 .3852 升到 .3963，**OPS 從 .7035 變成 .7146**。

上面那條「每一格次方乘 1.12294」的推導沒有失效：它解的是「聯盟平均在搬家前後維持
原值」，而那件事在搬家那一刻是成立的。變的是後來又動了一個獨立的旋鈕。護欄（OPS
的 .700 地板）因此多出一截餘裕——下次要再壓中段，彎度可以拉得比 5.637 更陡。


## 附錄（2026-09-24）：第二次搬家，+1

issue #9 把所有聯盟的 `par` 與 `min` 各 +1 時只做了一半——`reference_par` 留在 61，次方沒有重解。同一個絕對能力的產量因此下降（效果對了），但「大聯盟就是表面數字」那條性質斷了，敬遠的觸發點與獎項的 `d` 也跟著錯位。

補完的做法與本 ADR 一字不差：`reference_par` 61 → 62；每一格的次方乘 `ln(61/80) ÷ ln(62/80)` = 1.0638（安打 1.522 → 1.619、全壘打 6.0 → 6.383、二壘打、保送、盜壘、投手三振、局數體力、得分的腿）；沒有次方的格子重解兩端（被安打 1.490／0.943 → 1.542／0.996、被全壘打 9.561／38.684 → 9.305／40.833、控球 span 54.29 → 51.43、長打的球威斜率、盜壘刺、打者三振的 offset 與除數）；獎項的 `d` 19 → 18、賽揚 17 → 16；生涯難度的零點 `baseline_par` 46 → 47（這一格在 #9 時漏了，所有生涯評價分因此同乘了一個隱形的係數）。三壘打照舊不吃係數。

驗證：大聯盟聯盟平均 .265／OPS .704／防禦率 4.29 不變，能力 80 剛好是錨點；能力 65 的打者 .285、70 是 .322。敬遠的觸發線照本 ADR 的立場釘在絕對能力上（三圍約 73），換算成 d 是 +11。
