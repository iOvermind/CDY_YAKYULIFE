# 0050. 需要玩家回答的領域寫成步驟機，敘事留在流程

日期：2026-09-22

## 狀態

已接受

## 背景

棒球那一側的規則都是一算到底的純函式：`playSeason()`、`evaluateMovement()`、`runBallots()` 吃狀態、回結果，測試直接對著它們斷言。

感情不是。它中間夾著玩家的決定，而那些決定會改變後面的走向：風波要吞下去還是問清楚、外遇赴不赴約、被抓之後道歉還是簽字。於是整條感情線寫成了 continuation-passing 的巢狀 callback，整整 **850 行、23 個方法** 住在 `game.ts` 裡；`love.ts` 只擁有那幾條機率公式，大約是「感情」這個概念的 15%。

代價有三個：

**一、順序規則測不到，而那正是這一區的 bug 種類。**

```ts
// 被抓到之後那一年就結束了。沒有這道檢查的話，同一年會出現「劈腿曝光、
// 她提分手」然後立刻「要不要求婚」，對著一個已經走了的人跪下去。
this.#affairOrFlavour(() => {
  if (this.#love.status !== 'dating') { next(); return; }
  this.#proposalAsk(next);
});
```

同樣形狀的守衛在四個私有方法裡各寫一次。`love.test.ts` 碰不到任何一條——它只測得到機率公式。要驗它得打完一整段生涯，還得剛好抽中那條路。

**二、狀態有三種形狀要手工同步**：`LoveState`、`Game` 的兩個私有欄位（結婚年份、婚姻史）、`PlayerState.love` 的投影。

**三、加一條分支要讀 850 行**。三人行那次改動就是證據：入口有兩個、狀態有兩種形狀、而每一條守衛都得自己記得補。

## 決策

**需要玩家回答的領域，寫成一台步驟機（generator），而不是一串 callback。**

```ts
export function* loveYear(world: World, love: LoveState, ctx: LoveYearContext): LoveFlow
//        yield 出「這一步是什麼」，next(選項 id) 送回玩家的答案
```

分工：

| 擁有 | 誰 |
| :--- | :--- |
| 一年的順序、每一道守衛、`LoveState` 的所有變更、感情的所有抽取 | `loveYear.ts` |
| **選項 id** —— 那些字串會寫進重播日誌，它們是協定不是文案（ADR 0002） | `loveYear.ts` |
| 卡片與選項的**文字**（ADR 0025 的分工） | `game.ts` |
| 把步驟的 `effects` 兌現成能力、金錢、特性、榮銜 | `game.ts` |
| 機率公式（分手、風波、生子、離婚費…） | `love.ts` |

**能力與金錢用「意圖」跨過這條 seam**：步驟說的是「給接觸 +1」「隨機扣一項 3 點」「收 5% 生涯收入」，怎麼落地（蓄力槽、硬上限、量表的底）是 `game.ts` 的事——感情不必認識能力表。`effects` 在敘事之前兌現（扣的點數要寫進同一張卡片），`after` 在之後（特性解鎖自己會發一張卡，它該排在婚禮或分手那張卡的後面）。

**抽取與提問的順序逐格不變**，`ENGINE_VERSION` 維持 7：驅動端在收到步驟的當下兌現 effects，所以連「隨機挑一項能力」那幾次抽取都還落在原本的位置上。1258 + 42 項測試（含依種子的整局重播與 120 段生涯的護欄）全綠就是驗證。

## 後果

- 那條守衛變成三行就跑得完的測試：餵「赴約 → 簽字離婚」，斷言這一年**不會**再出現求婚那一步。
- 加一條分支只要讀 `loveYear.ts`：一年的形狀從上到下讀得完，不必在四個 callback 之間跳。
- `game.ts` 少了 850 行規則，多了約 500 行敘事——**行數不是重點**，重點是那 500 行裡沒有一條規則。
- 狀態只有一種形狀：`marriedYear` 與 `spouses` 收進 `LoveState`，`PlayerState.love` 只是它的投影。
- 代價是多一層間接：讀一段劇情要在「步驟」與「文案」兩支檔案之間對照。這是刻意的——文案改起來不會碰到規則，規則改起來不必重讀文案。
- 這個形狀可以複製到下一個「需要玩家回答」的領域（合約談判、交易否決、國家隊徵召）。它們今天都還是 callback。

## 替代方案

- **維持 callback，只把「選了之後會怎樣」抽成純函式。** 一半的 bug 抽得到，但順序規則仍然測不到——而那正是這一區真正的 bug 種類。
- **顯式游標的狀態機（`loveNext(state, cursor, choice)`）。** 狀態機可以序列化、看得見，但每一段都要手寫游標轉換，而重播本來就是「種子＋選項序列」，不需要存游標。
- **把文案也搬進 `love.json`。** 風波那五張卡已經在資料檔裡了，但其餘文案帶著 `<b class="hl">` 與插值，搬過去只會讓資料檔長出一套自己的模板語言。
