# ADR 0042: 投手的自責分，用打者那把尺

自責分不再是自己一條錨點式，改由**被打出來的事件**推導：被安打、被二壘打、被
三壘打、被全壘打、四壞與觸身球，送進打者側同一條 Bill James 得分創造。

## 背景

舊的自責分是這樣算的：

```
ER = 140 × (IP/200) × max(0.35, 1.55 − 1.15 × 能力佔比)
```

被安打有自己的一條、被全壘打有自己的一條、四壞有自己的一條，而自責分**與那三
條完全不相干**。於是一件在棒球裡不可能的事變成常態：**投手被打得很少，自責分
卻不會跟著少**。同一顆種子可以生出「每九局只被打五支安打、防禦率四點五」這種
球季，而畫面上那兩個數字並排在一起。

那道 `0.35` 的地板讓病更明顯——能力 80 的投手防禦率被卡在 2.1 上下，再怎麼強
也壓不下去，因為地板與被安打數無關，它只是一個常數。

第二個問題是**投打兩側用兩把不同的尺**。打者側早就有得分創造（`metrics.ts` 的
`runsCreated`），一個打者製造了多少分是算出來的；投手側卻是抽出來的。在一個封閉
的聯盟裡，全聯盟的得分必須等於全聯盟的失分——兩把尺各自校準，那條等式只能靠人
去對，而且每次動其中一邊就會鬆掉。

## 決定

**投手的自責分由他被打出來的那一份成績算出來，用的就是打者側那條式子。**

```
被打數 = 出局數 + 被安打
ER = (被上壘 × 被壘打數) ÷ (被打數 + 四壞 + 觸身) × scale
```

為了算得出壘打數，投手成績新增三個欄位：被二壘打、被三壘打、觸身球。切法是
**從被安打總數裡切**，不另外生成——先扣掉已經算好的被全壘打，再依比例切出三壘
打與二壘打，剩下的是一壘安。這樣切，現有的被安打校準完全站得住；讓新欄位自己
一條式子的話，三條加起來可能超過被安打總數，那道上限一夾比例就歪了。

`scale` 把「這些事件會生出多少分」折成「投手該負責的那一份」：殘壘、雙殺、換投
之後由接手負責的跑者，都讓實際自責分低於估計值。它由聯盟平均防禦率反解，不是
自由參數。

非自責失分那一條**不動**。它與能力無關——那是野手掉的球，而失誤造成的上壘本來
就不在投手的成績列裡。失分等於兩者相加。

**ERA+ 的分母跟著改。** 分母是「聯盟平均投手的防禦率」，而那個數字必須就是這組
公式在能力等於 par 時真正產生的結果。分母若留著舊的錨點式，ERA+ 100 會不再是
聯盟平均——而勝敗正是踩在 ERA+ 上面的（見 [ADR 0043](0043-wins-come-from-the-line-not-the-arm.md)）。
`eraAt()` 因此改成跑同一組公式，只是把波動與抖動關掉；受試者是**每一項能力都
等於同一個值**的投手，那是「能力比聯盟平均高 d 點」這句話唯一不偏袒任何一種
投手的讀法。

## 替代方案

**BaseRuns。** 現代最準的得分估算式，在極端情境（全部都是全壘打、全部都是一壘
安）仍然收斂。放棄的理由是它與打者側現有的尺不同源——那正是這份決策要修的東西。
真的需要極端值的準度時，兩側一起換成 BaseRuns 才是對的做法。

**FIP。** 只吃被全壘打、四壞與三振，被打進場內的球一律不算。它最省事，連新欄位
都不必加——但「投手被打得少，自責分就該少」正是它刻意不看的那一半。

**保留舊式子，只把地板拿掉。** 治得了 2.1 那個症狀，治不了被安打與自責分互不
相干這件事。

## 後果

*   投手成績多出三欄，而且它們不是裝飾——自責分吃它們。
*   聯盟平均防禦率仍然是 4.07（`scale` 就是照這個反解的），但**分佈的形狀變了**：
    被打得少的人防禦率真的低下去，地板不再擋著。
*   投打兩側的得分環境從此同源。封閉聯盟「得分等於失分」那條等式現在由結構保證，
    而不是由兩次獨立校準碰巧對上。護欄測試也改成量這件事。
*   抽取順序改變：舊版是局數 → 勝敗 → 被安打 → 自責分，新版必須先有事件才算得出
    自責分。引擎版本號因此跳到 6，舊的重播日誌一律拒絕。
*   養成期不受影響。那邊一年只有幾場球，切出來的長打全是抖動，因此三個新欄位在
    養成期一律為 0。
