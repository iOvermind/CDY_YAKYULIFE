# 計算公式總表

> 目前引擎裡**所有**會影響遊戲結果的計算，連同實測分佈與待討論的校準問題。
> 用途是把平衡攤開來討論，不是實作說明——實作細節看各模組的原始碼與註解。
>
> 所有可調參數都在 `client/src/data/` 的 JSON 裡，程式碼中不得出現寫死的平衡
> 數字（見 ROADMAP 階段一.七）。每條公式下方都標了參數的所在位置。

## 0. 亂數

一切隨機都來自世界種子衍生的六條子序列（`genesis` / `growth` / `events` /
`health` / `season` / `career`），見 [ADR 0002](../adr/0002-deterministic-rng-and-replay-log.md)。

```
子序列狀態 = hash("<種子>:<流名>")
```

**PRNG**：mulberry32 變體，逐位元移植自 `index_legacy.html:373-374`。

| 用途 | 公式 |
| :--- | :--- |
| 均勻亂數 | `next() ∈ [0, 1)` |
| 整數 | `int(a, b) = a + ⌊next() × (b − a + 1)⌋`，兩端皆含 |
| 機率判定 | `chance(p) = next() × 100 < p` |
| 加權挑選 | 依權重比例，鍵先排序確保結果不依賴物件走訪順序 |
| 加權洗牌 | 不放回的加權抽樣；權重主導前段名次，但任何項目都可能排到任何位置 |

📁 `client/src/engine/rng.ts`

## 2. 能力成長

### 2.1 成本曲線

```
成本(現值) = tiers 中第一個 現值 ≥ from 的 cost
若 現值 ≥ 潛力天花板：成本 ×= above_ceiling_multiplier
```

| 現值 | 成本 | 二刀流 |
| :--- | ---: | ---: |
| < 50 | 1 點 | 1 點 |
| 50–57 | 2 點 | 1 點 |
| 58–63 | 4 點 | 3 點 |
| 64–71 | 6 點 | 5 點 |
| ≥ 72 | 8 點 | 7 點 |
| 超過天花板 | ×3 | ×3 再 −3 |

二刀流不再有自己的一條曲線，改成**直接從成本扣點**：天賦之內每級 −1、天賦
之外每級 −3（在乘上懲罰倍率之後才扣）。舊做法是把整條門檻往後推，「便宜
多少」得靠兩張表對照才看得出來，而且 50–55 那一段對二刀流仍然是 1 點 1 級，
擲骰子看起來就像在直接加點數。

> 注意 50–57 這一階：基礎 2 點減 1 之後**仍然是 1 點**，二刀流在那一段還是
> 1:1。這是扣點模型的必然結果，已知並保留。

陡度接近舊版投手那條（最貴 8 點）。高段成長非常昂貴是刻意的——養成期的點數
必須有取捨，不能什麼都點滿。

> **這條曲線是所有數值的上游。** 它一改，養成期結束時的能力就整體位移，選秀
> 門檻、大賽門檻、二刀流門檻全都要跟著重量。實測：曲線從最貴 3 點改成 8 點
> 之後，交替配點者的綜合能力中位數從 46 掉到 42，二刀流取得率從 30% 掉到 3%
> ——門檻因此從 39 調到 36，才回到約四成。

**二刀流的機械性回報**：變貴的門檻往後推、超過天花板的懲罰較輕。

📁 `abilities.json` → `growth_cost`｜`client/src/engine/growth.ts`

### 2.2 蓄力槽

```
預算 = 投入點數 + 蓄力
while 預算 ≥ 成本(現值) 且 現值 < 絕對上限:
    預算 −= 成本(現值); 現值 += 1
蓄力 = 現值達上限 ? 0 : 預算
```

未滿一級的點數留著不蒸發。到達絕對上限後蓄力歸零，多的點數才算浪費。

**衰退一律 1:1，不吃成本曲線** —— 傷病不該因為能力高就扣得比較少。

### 2.3 絕對上限

```
絕對上限 = 80 + 上限提升點數        // 上限提升每項最多 5，故最高 85
```

上限提升**不直接加能力值**，只讓天花板與量表上限一起往上移。

### 2.4 訓練骰

```
骰數 = 加權抽(3:35%, 4:40%, 5:20%, 6:5%)
       + 外務纏身 −1
       + 逃學威龍 35% 機率 +1
       下限 2；傷缺整季固定 2
每顆點數 = int(1,6)｜高手高手高高手 int(4,6)｜十里坡劍神 int(3,6)
```

📁 `abilities.json` → `training_dice`

## 3. 能力評價

### 3.1 守備分

```
守備分(守位) = Σ 能力值 × 該守位的能力權重
```

| 守位 | 權重 |
| :--- | :--- |
| SS | 範圍 .50 / 接球 .30 / 臂力 .20 |
| 2B | 範圍 .45 / 接球 .40 / 臂力 .15 |
| 3B | 臂力 .45 / 接球 .35 / 範圍 .20 |
| CF | 範圍 .55 / 接球 .30 / 臂力 .15 |
| RF | 臂力 .45 / 範圍 .35 / 接球 .20 |
| LF | 範圍 .40 / 接球 .35 / 臂力 .25 |
| C | 接球 .40 / 配球 .40 / 臂力 .20 |
| 1B | 接球 .60 / 範圍 .20 / 臂力 .20 |

> **已知偏離 legacy**：舊版對同一個量有兩套權重，守備分那套不分守位，導致
> 強臂三壘手守備分為負。新版兩處共用同一組。見 `positions.json` 的 `_deviation`。

📁 `positions.json` → `ability_weights`｜`client/src/engine/rating.ts`

### 3.2 投手側評價

```
投手側 = 投球六項取前三 × (.42, .30, .18) + 體力 × .10
```

舊版取球速／控球／變化球固定三項；球系拆開後改為六項取前三，讓「一顆決勝球
加基本功」自然勝出。

### 3.3 野手側評價

```
打擊 = 擊球/力量/選球/速度 取前四 × (.38, .27, .20, .15)
野手側 = 打擊 × (1 − 守備權重) + 守備分 × 守備權重
指定打擊的守備分 = 守備分(1B) − 12
```

守備權重：SS/CF/C .30｜2B/3B .22｜RF .20｜LF .14｜1B/DH .12｜未指定 .24

### 3.4 綜合能力

```
綜合 = max(投手側, 野手側) + 特性修正       // 巧克力 −3
```

> **待校準**：另一側目前不計入。二刀流的價值在於「能同時貢獻兩種角色」，那要
> 等賽季模擬能讓同一個人既投又打時才體現得出來。

## 4. 養成期大賽

```
實力值 = 綜合能力 + 學校分級加成 + int(−波動, +波動)
名次 = thresholds 中第一個 實力值 ≥ 門檻 的名次，都不到則為最後一名
點數 = 名次點數 + ⌊綜合能力 / 22⌋
```

**每場大賽各擲一次波動** —— 同一個球員在同一年的四場大賽可以打出四種名次，
這是短期賽制的張力來源。

**三個變因的跨度是刻意配的**：學校 ±10（高中）／±6（國中）、波動 ±10（高中）
／±12（國中）、個人能力約 25 點。國中的波動大於高中，因為那個年紀的球員未成
熟、單場變數大，本來就更容易爆冷。

這組權重是為了讓**學校主導、個人微調**——現實中傳統強校本來就十拿九穩，一個
再強的球員也扛不動弱旅。改之前學校加成只有 ±4／±6，個人能力蓋過一切，等於
一個高中生扛起整支球隊。

| 階段 | 大賽 | 名次門檻 | 波動 | 對手 par |
| :--- | :--- | :--- | :--- | ---: |
| 國中 | 國中棒球聯賽 / 謝國城盃 / 青少棒錦標賽 / 華南金控盃 | 48 / 43 / 38 / 33 / 28 | ±12 | 28 |
| 高中 | 高中棒球聯賽 / 黑豹旗 / 玉山盃 / 王貞治盃 | 60 / 54 / 48 / 42 / 36 | ±10 | 38 |
| 大學 | 大學春季聯賽 / 大專盃 | 68 / 62 / 56 / 50 / 44 | ±10 | 46 |
| 業餘 | 成棒甲組春秋季聯賽 | 68 / 62 / 56 / 50 / 44 | ±10 | 48 |

名次點數：冠軍 6 / 亞軍 5 / 四強 4 / 八強 3 / 十六強 2 / 預賽出局 1

**綜合能力的額外點數（⌊綜合 / 22⌋）整季只加一次**，不是每場大賽都加。原本是
每場加，賽事從 3 場擴到 4 場、再加上最多 3 項國際賽之後，一年就能拿到 50 點
以上——能力點多到花不完，配點也就失去取捨。

**只有冠軍與亞軍計入生涯成就**（國際賽含季軍）。四強以下只給能力點、不留紀錄，
否則六年下來會累積出一長串「八強」「預賽出局」，把真正的榮譽淹掉。成就不帶
年份。

學校分級加成：國中 名門 +6 / 中堅 0 / 弱旅 −6；高中 名門 +10 / 中堅 0 / 弱旅 −10

出賽場次（依名次）：6 / 5 / 4 / 3 / 2 / 1 場

📁 `amateur.json` → `cups`｜`client/src/engine/amateur.ts`

## 4.5 養成期個人成績

`simulation_math.md` §3-4 的公式是為職業的百場球季寫的——先算上場時間再乘機率
屬性，那需要足夠的樣本數才收斂。養成期一場大賽只有幾場球，套同一套公式會把
隨機噪音放大到失真。因此改用「能力高過對手平均多少」直接推出率。

**出賽場次由名次決定**：冠軍 6 場、亞軍 5、四強 4、八強 3、十六強 2、預賽出局
1 場。打進冠軍戰的人本來就打比較多場，這讓成績自然反映實力。

```
率 = clamp(base + (能力 − 該階段 par) × per_point, min, max) + 噪音
```

| 項目 | 依據能力 | base | 每點 |
| :--- | :--- | ---: | ---: |
| 保送率（對打席） | 選球 | .08 | +.004 |
| 安打率（對打數） | 擊球 | .28 | +.006 |
| 全壘打佔安打比 | 力量 | .04 | +.004 |
| 盜壘嘗試率（對上壘） | 速度 | .08 | +.005 |
| 每場局數 | 體力 | 5 | +.08 |
| K/9 | 球速 | 6 | +.22 |
| BB/9 | 控球 | 4 | −.10 |
| 防禦率 | (球速+控球)/2 | 3.60 | −.09 |

打點 = 安打 × .55 + 全壘打；盜壘成功率固定 .72。

各階段的對手平均水準（`par`）：國中 28 / 高中 38 / 大學 46 / 業餘 48。

**角色判定**：投手側評價較高者投球、否則打擊；二刀流投打都算。

📁 `amateur.json` → `amateur_stats`、`cups.*.par`、`cups.games_by_rank`
｜`client/src/engine/amateurStats.ts`

## 5. 養成期國際賽

**出線方式只有一種：贏下掛著代表權的國內大賽。**

| 階段 | 國內大賽 | 對應國際賽 |
| :--- | :--- | :--- |
| 國中 | 謝國城盃 | LLB 世界次青少棒錦標賽 |
| 國中 | 青少棒錦標賽 | PONY 世界青少棒錦標賽 |
| 國中 | 華南金控盃 | WBSC U-15 世界盃 |
| 高中 | 王貞治盃 | PONY 小馬級世界青棒錦標賽 |
| 高中 | 玉山盃 | WBSC U-18 世界盃棒球賽 |
| 高中 | 黑豹旗 | BFA 亞洲 U-18 青棒錦標賽 |

國中層級這是真實的直通制。高中的 U-18 與亞青現實上是遴選國家隊，但打好國內
盃賽本來就是入選的主要依據，因此用同一套機制，**敘事上一律寫成「入選國家隊」**
而非「冠軍隊直接出賽」。

「國中棒球聯賽」與「高中棒球聯賽」不掛代表權 —— 它們是賽季最長的常規聯賽，
份量在於穩定累積，不在於一戰定生死。

```
能力加成 = clamp(⌊(綜合 − 38) × 0.35⌋, 0, 8)
亂數 = int(0, 100) + 能力加成
名次 = thresholds 中第一個 亂數 ≥ 門檻 的名次
```

名次由整體興衰決定，個人能力只佔一小部分 —— 這是刻意的：國家隊的成績不是
一個人的事。點數與國內大賽同級距（6/5/4/3/2），**兩者的榮譽各自獨立計算**。

📁 `amateur.json` → `amateur_international`、`cups.*.qualifies`

## 6. 事件卡

```
成功率(照常) = 50，高手高手高高手/十里坡劍神/今晚打老虎 → 65，何金銀 −10
成功率(保守) = min(95, 照常 + 20)
成功率(豪賭) = 照常 − 15，今晚打老虎不受此罰
                        一般人 35 / 50 / 70｜天才級 50 / 65 / 85
                        今晚打老虎 65 / 65 / 85（豪賭與照常齊平，不會更高）

效果幅度 = round(|效果值| × 應對倍率)，保底 1
應對倍率：保守 0.5 / 照常 1 / 豪賭 1.5
          今晚打老虎豪賭：成功 2 / 失敗 1

受傷機率增幅 = 保守 8% / 照常 12% / 豪賭 16%（今晚打老虎豪賭 12%）
```

> **與 legacy 的主要差別**：舊版只取效果值的正負號，幅度全由應對方式決定，
> 因此稀有事件無法比常見事件更重。多數舊事件的值是 1–2，照常應對的結果與舊版
> 相同，所以既有平衡沒有被動到。

`inj` 的幅度刻意**不吃**效果值 —— 受傷風險是「你冒了多大的險」，與事件加減
多少能力無關。

📁 `events.json` → `magnitude`、`injury_magnitude`、`good_result_chance`

## 實測分佈

養成六年結束時（各 400 段生涯，`startPosition: UTIL`）：

| 配點策略 | 弱側 p30 / p50 / p70 / max | 取得二刀流 |
| :--- | :--- | :--- |
| 刻意兩邊練（投手四項與打擊四項輪流） | 39 / 40 / 42 / 48 | **34%** |
| 只押注一兩項（vel + con） | 34 / 35 / 36 / 39 | **0%** |
| 專精野手 | 28 / 29 / 30 / 33 | **0%** |

（各 300 段生涯。）

> **校準事故：** 門檻先前是 36，那是對著一份壞掉的量測校準的。那支探針在選項
> 查找失敗時會退回第一個選項（體力），等於把大部分點數倒進一個對評價沒有權重
> 的地方，因此嚴重低估了認真配點者的能力——依它算出來的「43%」，換成正確的
> 配點其實是 93%。教訓：**量測程式本身要先驗證它真的在做你以為的事**，否則
> 校準出來的門檻只是在補償探針的 bug。

二刀流因此是一個 build 選擇：你得刻意兩邊練，而且要練得**夠廣**——投手側取
前三項加權、野手側看打擊與守備的組合，只堆一兩項會被評價公式吃掉。代價是
兩側都不會頂尖。

選秀輪次分佈：

| 配點策略 | 第 1 輪 | 第 2 輪 | 第 3–4 輪 | 第 5 輪以後 |
| :--- | ---: | ---: | ---: | ---: |
| 交替投打 | 16% | 69% | 15% | <1% |
| 只練單側 | 0% | 22% | 59% | 18% |

## 校準問題的細節

> 一覽表在文末的〈待辦總表〉，這裡是各項的來龍去脈。

### A. 選秀門檻過鬆（**最急**）

`draft.rounds.tiers` 是為三年高中制校準的。六年制把畢業時的綜合能力從約 38
拉到約 46，導致輪次全面前移 —— **人人都是前段指名，沒有落榜也幾乎沒有後段
輪次**。選秀因此失去張力，簽約金級距（第 1 輪 1000 萬 vs 第 8 輪 50 萬）也
形同虛設。

### A2. 養成期打擊率過高、分佈過窄（**次急**）

養成六年結束時的生涯成績（各 60 段生涯）：

| | p10 | p50 | p90 | 生涯場次 |
| :--- | ---: | ---: | ---: | ---: |
| 打擊率 | .453 | **.482** | .517 | 72 |
| 防禦率 | 2.04 | **2.34** | 2.79 | 93 |

兩個問題：

1. **中位數 .482 太高。** 台灣高中強打在大賽打到 .400–.450 已經是頂尖，.482
   應該是極少數的怪物數字，不該是中位數。防禦率 2.34 相對合理，但同樣偏好。
2. **分佈太窄。** 打擊率 p10 到 p90 只差 .064，等於每個人都差不多——實力差異
   沒有反映在成績上。原因是玩家的能力必然遠高於 `par`（配點都往同一邊集中），
   而噪音只有 ±.04。

可能的調整方向：拉高各階段的 `par`、降低 `hit_rate.per_point`、或加大噪音。
但這三者影響的東西不同——`par` 動的是「對手多強」，`per_point` 動的是「能力
換算成績的效率」，噪音動的是「短期賽的運氣成分」。要先決定哪一個才是失真的
來源。

### B. 大賽門檻是否要跟著調

高中大賽的冠軍門檻 52，在三年制下 120 場只出 1 次冠軍；六年制的能力提升後
應該變得可及。這可能正好，也可能變得太容易 —— 需要量測高中三年的名次分佈。
國中的門檻（40/35/30/25/20）是我依比例推的，完全沒有實測依據。

## 國際賽奪冠的回報：隔季的額外訓練骰

奪冠的回報不是點數，是**隔季多擲幾顆骰**。骰面維持 1–6 不變——披上中華隊戰袍
拿下冠軍帶來的是更好的訓練資源與眼界，不是每一球都變強。

**只有國際賽算，國內盃賽一律不給。** 國內大賽的回報已經是大賽點數與成就紀錄；
再給訓練骰等於同一件事獎勵兩次，而且名門學校的球員本來就容易橫掃國內盃賽，
會滾雪球到失控。

| 拿下國際賽冠軍時的階段 | 隔季多擲 |
| :--- | ---: |
| 國中 | +1 顆 |
| 高中 | +2 顆 |
| 職業 | +3 顆（事件尚未實作，預留） |

兩條規則讓它不會失控：

1. **同季多項國際賽冠軍取最高，不相加。**
2. **只延續一季，不累積。** 兌現後即清空。

實測（300 段養成生涯，均衡配點）：**只有 10% 的生涯拿得到，平均每段生涯觸發
0.11 次**。這是複合機率的結果——要先贏下掛著代表權的國內盃賽，才有資格打
國際賽，然後還要在國際賽奪冠。畢業綜合能力中位數 40。

> 校準風險：這是唯一的正回饋迴圈（贏 → 變強 → 更容易贏）。目前 10% 的觸發率
> 讓它幾乎不影響整體分佈，代價是多數玩家一輩子看不到這個機制。若要讓它更常
> 被看見，該調的是國際賽的資格門檻，不是加成的顆數。

## 職業球季（CPBL 主軸）

公式在 `docs/design/simulation_math.md` §3-4，參數全部在 `client/src/data/season.json`。
核心哲學是**先算時間，再算機率**：出賽場次與打席／局數先定下來，各項率再乘
上去。這跟養成期的簡化版相反——那邊一季只有幾場球，先算時間會被噪音吃掉。

### 出賽場次

`G = min(聯盟場次, 聯盟場次 × clamp(staF × posF, 0.1, 1.0) × perfF × random(0.97, 1.03))`

三個係數各自獨立：體力決定撐不撐得住、守位決定勞損、教練信任度決定排不排。

守位勞損以 DH 1.00 為基準向下遞減，捕手 0.80 是斷層級懲罰。**這讓「移防」成為
延長單季出賽壽命的真實手段**——老將把守位從游擊換到一壘，出賽場次會明顯回升。

### 升降級

判定一律看**能力相對該層級的 par／min**，不看單季成績。成績本身就是能力加噪音，
用成績判定等於把同一份噪音算兩次——運氣好的一季會直接把人送上一軍，運氣差的
一季會直接把人踢出去。

判定順序是升級 → 降級 → 戰力外。**先問升級是刻意的**：能力已經超過上一層級門檻
的人，不該因為還待在最低層級而在同一輪被問「要不要放掉他」。

戰力外有兩年寬限期，新人不會因為第一季達不到二軍標準就被釋出。

### 年齡曲線

26 歲之前緩升、26–30 巔峰持平、30 之後遞減且幅度隨年齡加速（上限每季 6 點）。

衰退不是等比落在每項能力上：**速度、守備範圍、球速先掉（×1.5），接觸、選球、
控球撐得比較久（×0.5）**。這是真實的老化順序，也讓老將的生存策略（移防、
改當接觸型打者）在數學上真的成立。

### 實測（200 段完整生涯，均衡配點的游擊手）

### 投手成績：自責分與勝敗

**自責分是算出來的，不是抽出來的。** 由被打出來的事件送進打者側同一條得分創造：

```
被打數 = 出局數 + 被安打
ER = (被上壘 × 被壘打數) ÷ (被打數 + 四壞 + 觸身) × scale
失分 = ER + 非自責（自己一條錨點，與能力無關）
```

長打從被安打總數裡切，不另外生成。`scale` 把「這些事件會生出多少分」折成「投手
該負責的那一份」，由聯盟平均防禦率反解。ERA+ 的分母走同一組公式（波動關掉），
因此 100 永遠就是聯盟平均。見 [ADR 0042](../adr/0042-runs-allowed-share-the-batters-ruler.md)。

**勝敗由成績與球隊相撞，不看能力。** 兩段式賠率：

```
賠率W = (隊勝率 / (1 − 隊勝率)) × 0.54 × (ERA+/100)^1.5
勝投  = 先發場次 × 賠率W/(1+賠率W)

剩餘   = 先發場次 − 勝投
賠率L = ((1 − 隊勝率) / 隊勝率) × 1.174 × (100/ERA+)^0.75
敗投  = 剩餘 × 賠率L/(1+賠率L)
無關勝敗 = 剩餘 − 敗投
```

決定率沒有參數，是導出的（實測 0.66–0.79，現實約 0.70）。兩個常數也不是自由參數：
`1.174` 由「聯盟平均投手在五成隊勝敗各半」反解，`0.75` 由 1978 年基德利那一季反解
（同一組參數對他的勝投預測 25.2 勝，實際 25 勝）。

後援走**機會 × 成功率**：機會由球隊勝場乘上小差距比例（比例隨球隊變強而下降），
成功率是 `0.85 × (ERA+/100)^0.16`。指數很小，99% 的情形落在 0.70–0.95，因此不設
硬上下限。國際賽沒有球隊戰力表，勝率改由母國頂級聯盟當年的浮動 par 對賽會 par 走
畢氏公式推——拿名次倒推是循環論證。見 [ADR 0043](../adr/0043-wins-come-from-the-line-not-the-arm.md)。

**校準的靶心**：平均值落在史上紀錄之下，靠波動與抖動在極端運氣好時破得了，不是
夾死在紀錄以下。3025 個真實生涯投手球季的實測極值：

| 項目 | 實測 | 史上紀錄 |
| :--- | ---: | ---: |
| 單季勝投 | 22 勝 4 敗 | 31 |
| 單季三振 | 274 | 383 |
| 單季局數 | 236 | 266 |
| 單季救援 | 49 | 62 |

20 勝以上佔 0.2%，十勝以上不敗的球季佔 0.13%（2013 年田中將大 24 勝 0 敗是真的
發生過的事）。

📁 `season.json` → `pitching.records`、`pitching.decision`
｜`client/src/engine/season.ts`

## 球隊戰力與奪冠機率

### 舊版的問題

舊版有**兩套互不相干**的東西：

```js
// index_legacy.html:1642 — 顯示給玩家看的
function teamChampRate(team){
  let h=0; for(...) h=(h*31+team.charCodeAt(i))&0xffff;
  return 8+(h%22);          // 8~29%，隊名的純函數
}

// index_legacy.html:2070 — 球季結束真正擲的
pc = clamp({CPBL:15,NPB:8,MLB:3.5}[top] + lastD*0.5, 2, {CPBL:26,NPB:15,MLB:9}[top])
```

上面那個只跟**隊名的字元碼**有關，註解寫「每年略有波動」但它是純函數、永遠
不變；下面那個只跟**球員自己的能力**有關，跟球隊一點關係都沒有。玩家在合約
畫面看到的「奪冠率 23%」與球季結束真正發生的事毫無關聯。

### 新版：只有一套

勝率是真的逐年模擬出來的，奪冠機率由勝率推導。

**開局**：進入職業的那一刻，聯盟每隊各抽一個基準勝率（0.40–0.60）作為「體質」。
抽一次就固定——**沒有這個錨，幾年之後所有球隊都會回歸同一個平均值，強弱隊的
區別就消失了**。

**每年**：

```
勝率 = 上季勝率 + (基準 − 上季勝率) × 0.35   ← 往自己的體質回歸
     + random(−0.06, +0.06)                  ← 補強或崩盤
     + 玩家貢獻（只加在自己的球隊）
勝率 clamp 到 [0.30, 0.70]
```

**玩家貢獻**：`clamp((綜合 − 聯盟 par) × 0.004, −0.04, +0.06)`。上下限刻意壓
得很窄——棒球是九個人的運動，再強的球員也翻不了一支爛隊。

**奪冠機率**：`勝率⁴ / Σ(全聯盟勝率⁴)`，clamp 到 [1%, 55%]。取四次方是為了
放大強隊的優勢——短期賽制有運氣成分，但一支勝率七成的球隊本來就該明顯比
五成的容易奪冠，線性換算會把這個差距抹平。全聯盟的機率加起來是 1。

## 進階指標

三者都要跟聯盟平均比，因此核心是基準線。**基準線是算出來的，不是另外抄一份
數字**——各項率的 `base` 值定義上就是「與聯盟同水準時的值」，把它們組成一條
平均成績列即可。抄一份的話，調整率的設定時基準線會偷偷失準。

| 指標 | 公式 | 100 的意義 |
| :--- | :--- | :--- |
| ERA+ | `100 × 聯盟ERA ÷ 個人ERA` | 聯盟平均 |
| OPS+ | `100 × (OBP/lgOBP + SLG/lgSLG − 1)` | 聯盟平均 |

OPS+ 是**上壘與長打各自相對聯盟再相加**，而不是把 OPS 直接相除——兩者的離散
程度不同，直接相除會低估上壘型打者。

### Win Shares

完整的 Bill James WS 要把球隊的總勝利分配給全隊，需要全隊的成績。這裡改用
「相對替代水準的貢獻」直接估算個人值：

```
打者 WS = max(0, (RC − 聯盟每打席RC × PA × 0.52) ÷ 10 × 3)
投手 WS = max(0, ((聯盟ERA × 1.25 − ERA) ÷ 9 × IP) ÷ 10 × 3)
```

`RC` 是 Bill James 最早的基本版：`上壘次數 × 壘打數 ÷ (打數 + 保送)`。

> **這是近似值。** 數量級與真正的 WS 相當，但**不保證全隊加總等於球隊勝場的
> 三倍**——那是真 WS 的定義性質。取捨換來的是不需要模擬隊友的成績。

沒有樣本時 ERA+／OPS+ 回傳 null，介面畫破折號而不是 0——0 會被誤讀成「差到
極點」。

### 量測的教訓

**量測程式本身要先驗證它真的在做你以為的事。** 這份文件裡有兩個數字是被壞掉的
探針騙出來的：

1. 二刀流門檻 36 —— 探針在選項查找失敗時退回第一個選項（體力），把點數倒進一個
   對評價沒有權重的地方，因此嚴重低估了認真配點者的能力。
2. 「養成六年後能力總和下降 107 點」—— 探針判斷「是否已進入職業」只看有沒有
   `draft:` 提問，但指名不可拒絕時選秀根本不產生提問，養成期的量測因此一路跑到
   三十幾歲，把年齡衰退算進養成的成長裡。

兩次都差點導致「調參數去補償 bug」。看到不合理的數字時，先懷疑量測。
