# 模擬引擎運算數學模型 (Simulation Math Design)

> 本文件記錄未來 `SimulationEngine.ts` 實作時的數學運算藍圖，確保棒球數據的合理性、波動性與邊界安全。

## 1. 核心哲學：先算時間，再算機率 (Rate Projection)

所有傳統的累積數據（安打、全壘打、三振）絕對不能直接憑空擲骰產生。
必須嚴格遵守：**「先求得上場時間（PA/IP），再乘以球員的機率屬性（Rate %）」**。

## 2. 隨機性的來源 (Randomness)

本文件後續所有公式裡的 `random(a, b)`、機率判定與擲骰，**一律不得**使用原生 `Math.random()`。全部必須取自種子衍生的確定性序列——這是 `README.md` 對玩家的承諾「同種子＋同選擇＝同一段人生」的實作基礎，詳見 [ADR 0002](../adr/0002-deterministic-rng-and-replay-log.md)。

### 2.1 六條子序列

主種子衍生出六條互不干擾的子序列。每一次抽取都屬於其中一條：

| 子序列 | 涵蓋 |
| :--- | :--- |
| `genesis` | 開局生成：初始能力、潛力天花板、出身高中 |
| `growth` | 訓練骰、蓄力槽、能力成長與衰退 |
| `events` | 事件卡的抽取與好壞判定 |
| `health` | 傷病判定、TJ 量表 |
| `season` | 賽季模擬與成績結算——**本文件第 3、4 節的公式全部走這條** |
| `career` | 選秀、合約、交易、國際賽、感情、名人堂票選 |

**歸屬規則**：一次抽取歸屬於**執行它的領域函式**，不歸屬於呼叫者。

分流的目的不是保護舊種子（生涯一旦分岔，後續一切都會不同），而是**受控實驗**：固定傷病序列、只變動賽季模擬的參數，才能在重新校準數值時分離出單一變因。

### 2.2 修正值與抽取的分界

跨系統流動的**只有修正值，不是抽取**。這是既有實作的模式，重寫時必須保持。

以事件卡造成的受傷為例：事件卡的 `bad_effects.inj` 只是累加到一個修正值（`index_legacy.html` 的 `S.injNext`），當下**不抽任何數**；真正的判定發生在賽季健康檢查的單一位置，`受傷機率 = 15 + 修正值 + 年齡調整 + 特性調整`，只擲一次。

保持這個分界有兩個好處：一次判定只有一個地方負責，且子序列的歸屬永遠明確。

### 2.3 禁止事項

- **禁止**在任何影響遊戲結果的地方呼叫原生 `Math.random()`。
- 純視覺用途（例如擲骰動畫的數字跳動）**可**使用原生亂數，但**必須**確保它不回寫任何遊戲狀態——顯示的數字與實際採用的數值必須來自同一個確定性來源。
- **禁止**在同一次判定中從兩條不同的子序列取數。

## 3. 野手出賽與打席公式 (Plate Appearances)

### 3.1 實際出賽場次 (G)
出賽場次是所有數據的基石，由三個核心變數與隨機噪音組成：
**`G = Math.round( Math.min(聯盟總場次, 聯盟總場次 * clamp(staF * posF, 0.1, 1.0) * perfF * random(0.97, 1.03)) )`**

*   **體力健康係數 (`staF`)**：由球員 `sta` 屬性轉換，滿分 1.0。
*   **教練信任度 (`perfF`)**：依據實力 `d` 值決定，打不好會被下放替補。
*   **守備位置修正係數 (`posF`)**：真實反映不同守位的體能勞損，以 DH 為 1.00 基準向下遞減。這使得球員可以透過「移防」來延長單季出賽壽命。
    *   `DH` (指定打擊): **1.00** (基準值，無守備勞損)
    *   `1B` (一壘手): **0.99** (移動少、負擔極低)
    *   `LF` (左外野): **0.98** (接球定位、傳球負擔小)
    *   `3B/RF` (三壘/右外野): **0.97** (反應快或需長傳，跑動中等)
    *   `2B` (二壘手): **0.96** (跑動多、需防衝撞)
    *   `SS/CF` (游擊/中外野): **0.95** (高強度橫移衝刺、全場防守核心)
    *   `C` (捕手): **0.80** (斷層級懲罰，極難全勤)
*   *備註*：最後乘上的 `random(0.97, 1.03)` 模擬因隊友受傷而被迫加班，或是感冒請假等不可抗力，並透過 `Math.min` 確保絕不超過聯盟上限。

### 3.2 賽季打席數 (PA) - 引入合理隨機性
*   為了避免產出極端值（如單季 700+ PA），PA 的計算必須建立在 G 之上，並加入合理的常態分佈噪音。
*   **PA 基數係數 (Base PA/G)**：介於 `[4.0, 4.3]` 之間。由教練團信任度與打線位置（例如第一棒通常較多）決定。
*   **隨機波動**：
    *   乘數噪音：`[0.97, 1.03]` (反映延長賽多寡、球隊整體上壘率導致的打席變化)
    *   絕對噪音：`[-G/8, +G/8]` 打席的隨機加減，確保隨機性會隨著出賽場次動態縮放，不會造成少場次出賽者的數據崩壞。
*   **總公式範例**：
    `PA = Math.round( G * (4.0 ~ 4.3) * random(0.97, 1.03) + random(-G/8, G/8) )`

### 3.3 基礎打擊結算 (AB & Hits)
*   `BB (一般保送)` = `PA * BB%` (保送率由球員的 `eye` 選球能力與聯盟基準計算)
*   `IBB (故意四壞)` = 採用**指數型恐懼值 (Domination)** 計算。
    *   *邏輯*：對手只會敬遠重砲手，不會敬遠快腿（因為敬遠快腿等於免費送他上二壘）。
    *   *公式*：`Dom = (pow + con + eye - spd/4) / 180`
    *   如果 `Dom > 1.0`（代表該球員是極端神獸），則：
        `IBB = Math.round( PA * Math.pow(Dom, 2) / 16 * random(0.85, 1.15) )`
    *   否則 `IBB = 0`。
*   `AB (打數)` = `PA - BB - IBB - 其他`
*   `H (安打)` = `AB * AVG` (打擊率由 `con` 接觸率計算)
*   `HR (全壘打)` = `AB * HR%` (全壘打率由 `pow` 力量計算)
*   `1B, 2B, 3B` = 將剩餘的 `(H - HR)` 依球員速度 (`spd`) 比例分配。

## 4. 投手出賽與局數公式 (Innings Pitched)

### 4.1 先發投手 (SP)
*   **先發場次 (GS)**：受限於輪值，最高為 `聯盟場次 / 5`。
*   **投球局數 (IP)**：
    `IP = GS * 每場平均局數 (4.5 ~ 7.0)`
    *(平均局數由投手的體力與壓制力決定，會加入小幅隨機波動)*

### 4.2 後援投手 (RP/CL)
*   **出賽場次 (G)**：由教練信任度決定，通常為 40~80 場。
*   **投球局數 (IP)**：
    `IP = G * (1.0 ~ 1.2)` + 延長賽偶爾跨局的隨機噪音。

## 5. 投手變化球系與運算特性 (Pitch Repertoire & Traits)

在引擎運算中，不再使用單一的 `brk` (變化度) 數值。投手的變化球被拆分為四大球系，各自帶有獨特的數學加成與特性：

### 5.1 橫向變化系 (Sweeping / Breaking)
*   **代表球種**：滑球 (Slider)、橫掃滑球 (Sweeper)、卡特球 (Cutter)。
*   **數學特性**：
    *   **三振型**：高機率誘使揮空，大幅提升三振率 (K%)。
    *   **同邊優勢**：面對同打擊慣用手 (如右投對右打) 時，加成放大；面對反邊打者時效果銳減。
    *   **高風險**：失投時容易被擊出深遠飛球，全壘打被擊出率 (HR%) 較高。

### 5.2 縱向掉落系 (Vertical / Dropping)
*   **代表球種**：曲球 (Curveball)、12-6 大曲球 (12-6 Curve)。
*   **數學特性**：
    *   **破壞擊球點**：大幅降低打者的確實擊球率（擊球），製造大量高飛必死球 (Pop-up) 或軟弱滾地球。
    *   **無左右病**：垂直掉落的軌跡不受打者左右站位影響。

### 5.3 變速與下沉系 (Off-speed / Split)
*   **代表球種**：變速球 (Changeup)、指叉球 (Splitter)、伸卡球 (Sinker)。
*   **數學特性**：
    *   **滾地球大師**：大幅提升滾地球比例 (GB%)，極易製造雙殺打 (DP)，且有效降低全壘打被擊出率 (HR%)。
    *   **反邊剋星**：變速球是對付反方向打者的最佳武器，能有效抵銷對手的左右打優勢。

### 5.4 特殊奇招系 (Specialty / Gimmick)
*   **代表球種**：蝴蝶球 (Knuckleball)、螺旋球 (Screwball)。
*   **數學特性**：
    *   **蝴蝶球專屬效果 (Stamina Boost)**：體力消耗係數極小。擁有高等級蝴蝶球的投手，其 `staF` 衰減速度慢，且單季極限局數可突破常規限制。
    *   **極端隨機性**：單場表現的隨機噪音極大（骰子型投手），完全無視常規的打者數據壓制公式。
