# 模擬引擎運算數學模型 (Simulation Math Design)

> 本文件記錄未來 `SimulationEngine.ts` 實作時的數學運算藍圖，確保棒球數據的合理性、波動性與邊界安全。

## 1. 核心哲學：先算時間，再算機率 (Rate Projection)

所有傳統的累積數據（安打、全壘打、三振）絕對不能直接憑空擲骰產生。
必須嚴格遵守：**「先求得上場時間（PA/IP），再乘以球員的機率屬性（Rate %）」**。

## 2. 野手出賽與打席公式 (Plate Appearances)

### 2.1 實際出賽場次 (G)
出賽場次是所有數據的基石，由三個核心變數與隨機噪音組成：
**`G = Math.round( Math.min(聯盟總場次, 聯盟總場次 * clamp(staF * posF, 0.1, 1.0) * perfF * random(0.97, 1.03)) )`**

*   **體力健康係數 (`staF`)**：由球員 `sta` 屬性轉換，滿分 1.0。
*   **教練信任度 (`perfF`)**：依據實力 `d` 值決定，打不好會被下放替補。
*   **守備位置修正係數 (`posF`)**：真實反映不同守位的體能勞損，以 DH 為 1.00 基準向下遞減。這使得球員可以透過「移防」來延長單季出賽壽命。
    *   `DH` (指定打擊): **1.00** (基準值，無守備勞損)
    *   `1B` (一壘手): **0.99** (移動少、負擔極低)
    *   `LF` (左外野): **0.98** (接球定位、傳球負擔小)
    *   `3B/RF` (三壘/右外野): **0.97** (反應快或需長傳，跑動中等)
    *   `2B` (二壘手): **0.96** (跑動多、需防衝撞)
    *   `SS/CF` (游擊/中外野): **0.95** (高強度橫移衝刺、全場防守核心)
    *   `C` (捕手): **0.80** (斷層級懲罰，極難全勤)
*   *備註*：最後乘上的 `random(0.97, 1.03)` 模擬因隊友受傷而被迫加班，或是感冒請假等不可抗力，並透過 `Math.min` 確保絕不超過聯盟上限。

### 2.2 賽季打席數 (PA) - 引入合理隨機性
*   為了避免產出極端值（如單季 700+ PA），PA 的計算必須建立在 G 之上，並加入合理的常態分佈噪音。
*   **PA 基數係數 (Base PA/G)**：介於 `[4.0, 4.3]` 之間。由教練團信任度與打線位置（例如第一棒通常較多）決定。
*   **隨機波動**：
    *   乘數噪音：`[0.97, 1.03]` (反映延長賽多寡、球隊整體上壘率導致的打席變化)
    *   絕對噪音：`[-G/8, +G/8]` 打席的隨機加減，確保隨機性會隨著出賽場次動態縮放，不會造成少場次出賽者的數據崩壞。
*   **總公式範例**：
    `PA = Math.round( G * (4.0 ~ 4.3) * random(0.97, 1.03) + random(-G/8, G/8) )`

### 2.3 基礎打擊結算 (AB & Hits)
*   `BB (一般保送)` = `PA * BB%` (保送率由球員的 `eye` 選球能力與聯盟基準計算)
*   `IBB (故意四壞)` = 採用**指數型恐懼值 (Domination)** 計算。
    *   *邏輯*：對手只會敬遠重砲手，不會敬遠快腿（因為敬遠快腿等於免費送他上二壘）。
    *   *公式*：`Dom = (pow + con + eye - spd/4) / 180`
    *   如果 `Dom > 1.0`（代表該球員是極端神獸），則：
        `IBB = Math.round( PA * Math.pow(Dom, 2) / 16 * random(0.85, 1.15) )`
    *   否則 `IBB = 0`。
*   `AB (打數)` = `PA - BB - IBB - 其他`
*   `H (安打)` = `AB * AVG` (打擊率由 `con` 接觸率計算)
*   `HR (全壘打)` = `AB * HR%` (全壘打率由 `pow` 力量計算)
*   `1B, 2B, 3B` = 將剩餘的 `(H - HR)` 依球員速度 (`spd`) 比例分配。

## 3. 投手出賽與局數公式 (Innings Pitched)

### 3.1 先發投手 (SP)
*   **先發場次 (GS)**：受限於輪值，最高為 `聯盟場次 / 5`。
*   **投球局數 (IP)**：
    `IP = GS * 每場平均局數 (4.5 ~ 7.0)`
    *(平均局數由投手的體力與壓制力決定，會加入小幅隨機波動)*

### 3.2 後援投手 (RP/CL)
*   **出賽場次 (G)**：由教練信任度決定，通常為 40~80 場。
*   **投球局數 (IP)**：
    `IP = G * (1.0 ~ 1.2)` + 延長賽偶爾跨局的隨機噪音。
